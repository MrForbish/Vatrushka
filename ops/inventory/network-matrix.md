# Матрица частной сети

Метки: **fact**, **inference**, **assumption**, **unknown**, **proposal**.

| Источник | Назначение | Необходимая цель | Транспорт | Состояние |
| --- | --- | --- | --- | --- |
| Linux Запуск | Production | развертывание только обёртки | SSH с закреплённым ключом хоста | **предложение** |
| Linux Запуск | Staging | развертывание только обертки | SSH с закрепленным ключом хоста | **предложение** |
| Production | Наблюдатель | метрики и логи | приватный маршрут WireGuard | **факт (2026-07-25):** настроен для нового хоста production; соединение проверено, при этом старый пир production остается неизменным. |
| Staging | Наблюдатель | метрики и логи | приватный маршрут WireGuard | **предложение** |
| Linux Исполнитель | Наблюдатель | метрики и логи исполнителя | приватный маршрут WireGuard | **предложение** |
| Оператор | Наблюдатель | Grafana администрация | VPN или SSH туннель | **предложение** |
| Государственные клиенты | Production | API, WebSocket, LiveKit/TURN | HTTPS/WSS и утвержденные UDP/TCP медийные порты | **факт** для текущей production топологии |

- **факт:** текущая развертка продукта достигает Observer, проксируя SSH через хост production.
- **вывод:** этот путь лишний образом связывает доступ к продукту и наблюдателю.
- **факт (2026-07-25):** новый хост production и Observer имеют выделенный одноранговый маршрут WireGuard. Их приватные адреса и данные о пире намеренно не хранятся в Git. Существующий пир production остается активным до завершения миграции трафика.
- **неизвестно:** группы брандмауэра провайдера, выделение публичного IP и владение DNS.
- **предложение:** заменить пересылку от production к Observer SSH на прямой трафик наблюдаемости в частной сети. Не открывать Prometheus, Loki или Grafana публично без отдельно утвержденной политики доступа.
