# Инвентаризация документации

| Класс | Статус | Доказательства и действия |
| --- | --- | --- |
| Канонические спецификации продукта/технические/тестирования/безопасности/релиза | активные | Ссылки `AGENTS.md`; сохранить. |
| ADRs под `docs/adr/` | исторический_запись | Архитектурные решения, включая настройки, updater, наличие, обмен сообщениями и LiveKit; сохранить. |
| `docs/delivery/*` | активный/исторический-запись | Текущие планы доставки плюс доказательства аудита и отката; сохранить и держать индекс в `docs/delivery/README.md`. |
| Руководства/архитектура наблюдаемости | активно | Используется для развернутого мониторинга и операционной проверки; сохранять. |
| проигнорированный локальный пакет Codex | принадлежащий пользователю | Не является каноническим источником репозитория; не удаляйте и не переписывайте его в этой проверке. |

Ни один документ не помечен `dead-confirmed`: удаление требует доказательства дубликата, отсутствия входящих ссылок, отсутствия роли ADR/release/audit и наличия заменяющей ссылки.
