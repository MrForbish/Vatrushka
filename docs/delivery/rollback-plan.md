# План отката

Метки: **fact**, **inference**, **assumption**, **unknown**, **proposal**.

- **факт:** сегодня нет защищённой `rollback_production` работы.
- **предложение:** каждый кандидат на повышение стабильности создает манифест отката, ссылающийся на последние известные исправные, неизменяемые дайджесты образов и метаданные desktop updater.
- **предложение:** `rollback_production` будет одной защищённой ручной работой GitLab, доступной только через проверенный поток тегов/релизов. Она проверяет манифест отката, вызывает `vatrushka-rollback`, а затем выполняет проверки готовности, smoke-тесты и проверки наблюдаемости.
- **предложение:** откат никогда не выполняет автоматические разрушительные операции по понижению базы данных. Только обратимо-совместимые миграции могут сопровождать автоматический откат приложения.
- **предложение:** стабильный updater манифест остаётся без изменений до прохождения проверки; откат клиента — это явная, проверенная публикация ранее проверённого стабильного потока.
- **неизвестно:** текущие данные восстановления резервной копии и матрица совместимости миграции приложений.
