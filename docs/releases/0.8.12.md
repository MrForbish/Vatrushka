# Vatrushka 0.8.12

Production наблюдаемость и выпуск ремонта конфигурации runtime.

- Добавляет явный публичный зонд доступности HTTPS для LiveKit и восстанавливает модуль зонда TURN TLS.
- Делает `/opt/vatrushka` каноническим корнем runtime, когда существует его управляемый оператором `.env`.
- Сбой развертывания, если `HAWK_ENABLED=true` не приводит к активному репортеру API.
- Не включена миграция PostgreSQL, миграция с Redis-ключом или изменение жизненного цикла S3.
