# Vatrushka 0.8.12

Production observability and runtime-configuration repair release.

- Adds an explicit public HTTPS availability probe for LiveKit and restores the TURN TLS probe module.
- Makes `/opt/vatrushka` the canonical runtime root when its operator-managed `.env` exists.
- Fails deployment if `HAWK_ENABLED=true` does not result in an active API reporter.
- No PostgreSQL migration, Redis-key migration, or S3 lifecycle change is included.
