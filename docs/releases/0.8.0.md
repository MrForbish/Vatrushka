# Vatrushka 0.8.0

Version 0.8.0 completes the reliability and observability scope for production operation and includes the accumulated messaging, media and realtime fixes.

## Product and realtime

- Screen sharing, voice presence and messaging received reliability fixes, safer reconnect handling and clearer client feedback.
- Profile and server media, notifications, message history, composer attachments and the shared desktop shell were hardened for everyday use.
- Voice presence remains LiveKit-confirmed, with Redis as a recoverable realtime projection and WebSocket fan-out to clients.

## Observability

- Provisioned Grafana dashboards cover application and HTTP behavior, messaging, voice and screen sharing, PostgreSQL, Redis, S3, email and external availability.
- Prometheus recording rules and alerts expose API, WebSocket, LiveKit webhook, screen-share, authentication, S3 and dependency failures with bounded labels.
- Loki dashboards, a canary and host/container dashboards provide actionable diagnostics without routing internal Loki gRPC through the egress proxy.

## Data and rollout

- No new PostgreSQL migration is introduced by this release; migrations `0024` through `0026` remain the current schema endpoint.
- Redis realtime and observability keys are ephemeral or recoverable. Their loss is repaired by LiveKit reconciliation and normal rescrapes.
- Rollback restores the previous API/desktop build and updater feed. Existing additive database changes remain compatible with the previous binary.
- After deployment, use the Grafana Service Health & SLO dashboard and the observability runbook to establish a seven-day production baseline before tuning warning thresholds.
