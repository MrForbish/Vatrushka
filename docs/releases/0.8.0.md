# Vatrushka 0.8.0

Версия 0.8.0 завершает охват надежности и наблюдаемости для операции production и включает накопленные исправления для сообщений, медиа и работы в реальном времени.

## Продукт и в реальном времени

- Функции совместного использования экрана, голосового присутствия и обмена сообщениями получили исправления надежности, более безопасную обработку повторного подключения и более четкую обратную связь для клиента.
- Профиль и серверные медиа, уведомления, история сообщений, вложения компоновщика и общий desktop контейнер были укреплены для повседневного использования.
- Присутствие голоса остается подтвержденным LiveKit, с Redis как восстанавливаемой проекцией в реальном времени и распределением WebSocket клиентам.

## Наблюдаемость

- Предоставленные Grafana панели мониторинга охватывают поведение приложения и HTTP, обмен сообщениями, голосовую связь и совместное использование экрана, PostgreSQL, Redis, S3, электронную почту и внешнюю доступность.
- Prometheus правила записи и оповещения выявляют API, WebSocket, LiveKit вебхук, совместный доступ к экрану, аутентификацию, S3 и сбои зависимостей с ограниченными метками.
- Панели мониторинга Loki, канарейка и панели мониторинга хоста/контейнера предоставляют действенную диагностику без маршрутизации внутреннего Loki gRPC через прокси исходящего трафика.

## Данные и внедрение

- Новая миграция PostgreSQL не вводится этим выпуском; миграции `0024` до `0026` остаются текущей конечной точкой схемы.
- Redis ключи реального времени и наблюдаемости являются эфемерными или восстанавливаемыми. Их потеря устраняется с помощью согласования LiveKit и обычного повторного сканирования.
- Откат восстанавливает предыдущую сборку API/desktop и updater поток. Существующие изменения базы данных добавок остаются совместимыми с предыдущей бинарной версией.
- После развертывания используйте панель состояния сервиса Grafana и панель SLO, а также средства наблюдаемости runbook, чтобы установить семидневный базовый показатель production перед настройкой порогов предупреждений.
