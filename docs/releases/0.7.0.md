# Vatrushka 0.7.0

Версия 0.7.0 завершает текущий игровой UX, охват голосового присутствия и надежности и упаковывает его через защищенный GitLab релиз workflow.

## Продукт

- Игровой Дом содержит ровно четыре центральных блока: компактный статус голоса, быстрый возврат, активные голосовые пространства и друзья/активность из реально доступных контактов.
- Аутентификация использует окончательную отметку Vatrushka и одобренный игровой фон, при этом сохраняются пароли, электронная почта/TOTP/контракты восстановления и сброса.
- Действия с голосом дома подключаются без скрытия библиотеки сервера; действия с контактами открывают существующий прямой разговор.
- Публичные серверы, медиа сервера/профиля, адаптивная панель заголовка Windows и обнаружение updater готовы к production.

## Голос и в реальном времени

- LiveKit остается авторитетным для присутствия в медиа; Redis хранит восстанавливаемую голосовую проекцию и версионированные снимки сервера.
- Действия пользователя и модератора являются идемпотентными, проверяются на разрешения, находятся в ожидании до подтверждения и доступны через перетаскивание или клавиатуру UI.
- Множественный экземпляр Pub/Sub, дедупликация вебхуков, защита при позднем выходе и периодическая проверка восстанавливают пропущенные события.
- Совместное использование экрана использует безопасный видео-только режим резервного копирования, когда системное аудио не может исключить вывод Vatrushka.

## Надежность и операции

- Доставка уведомлений по электронной почте является надежной и идемпотентной через транзакционный outbox.
- Специальный стек наблюдаемости включает Prometheus, Grafana, Loki, Alertmanager, Blackbox и приватные агенты; переключение production остается отдельно проверяемым этапом инфраструктуры.
- CI выполняет реальные PostgreSQL/Redis интеграционные тесты, renderer/Electron поведение, 33 Windows визуальных сценария и бюджеты пакетов.

## Данные и внедрение

- миграция `0025_mean_emma_frost` добавляет уникальный индекс durable-email outbox;
- миграция `0026_odd_wild_pack` добавляет видимость сервера, хранение обложек профиля и индекс публичного сервера;
- голосовые ключи Redis могут быть восстановлены и могут быть восстановлены из сверки LiveKit;
- production использует `VOICE_MOVE_STRATEGY=controlled-reconnect`, при этом флаги DnD и перемещения модератора включаются только после проверки работоспособности webhook/readiness;
- откат восстанавливает предыдущую версию сервера и updater канал; добавочные PostgreSQL столбцы/индексы остаются безопасными для предыдущего бинарного файла.
