# Vatrushka 0.4.1

Версия 0.4.1 — это desktop UX и патч надежности медиа-устройств. Она не добавляет миграцию базы данных и не изменяет публичный контракт API.

## Изменения, видимые пользователю

- Вход по паролю, регистрация, заполнение профиля и первый главный экран теперь используют текущую систему дизайна Vatrushka и постоянную оболочку приложения.
- Подключение к голосовому каналу удерживает серверы, текстовые/голосовые каналы и участников на экране. Активное подключение отображается в боковой панели сервера.
- Элементы управления микрофоном и выводом являются элементами выбора пользовательской системы дизайна. Electron предоставляет доступ к аудио только доверенной основной рамке, Chromium отображает реальные метки Windows, и нумерованные имена-заполнители больше не создаются.
- Широкие элементы управления устройством inline были перенесены в компактное всплывающее окно, чтобы два селектора не сталкивались друг с другом или с голосовыми командами.
- Тост updater появляется только для доступного, загружаемого или готового обновления. Его можно закрыть, и он больше не показывает нефункциональную ручную проверку текущей версии.

## Проверка

- renderer: нормализация устройства, пользовательский выбор, постоянная голосовая оболочка и видимость/закрытие updater;
- Storybook: взаимодействие и проверки топора для каждого story;
- Electron: разрешение только для аудио и ненулевые метки устройств медиа в доверенном renderer;
- Windows визуальные эталоны: аутентификация, главная, всплывающее окно устройства, подключённая голосовая оболочка и уведомление о готовности обновления.

## Внедрение

Соберите установленного клиента NSIS и опубликуйте `Vatrushka-Setup-0.4.1-x64.exe` вместе с его блок-картой перед заменой `latest.yml`. Установленные клиенты версии 0.4.0 могут загрузить версию 0.4.1 на месте. Пользователи портативной версии должны заменить свой исполняемый файл вручную.
