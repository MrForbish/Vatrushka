# Vatrushka 0.4.1

Version 0.4.1 is a desktop UX and media-device reliability patch. It does not add a database migration or change the public API contract.

## User-visible changes

- Password login, registration, profile completion and the first home screen now use the current Vatrushka design system and persistent app shell.
- Joining a voice channel keeps servers, text/voice channels and members on screen. The active connection is shown in the server sidebar.
- Microphone and output controls are custom design-system pickers. Electron grants audio access only to the trusted main frame, Chromium exposes actual Windows labels, and numbered placeholder names are no longer generated.
- The wide inline device controls moved into a compact popover, preventing the two selectors from colliding with each other or the voice actions.
- The updater toast appears only for an available, downloading or ready update. It is dismissible and no longer shows a non-functional manual check for the current version.

## Verification

- renderer: device normalization, custom selection, persistent voice shell and updater visibility/dismissal;
- Storybook: interaction and axe checks for every story;
- Electron: audio-only permission and non-empty media-device labels in the trusted renderer;
- Windows visual baselines: auth, home, device popover, connected voice shell and ready update toast.

## Rollout

Build the installed NSIS client and publish `Vatrushka-Setup-0.4.1-x64.exe` plus its blockmap before replacing `latest.yml`. Installed 0.4.0 clients can download 0.4.1 in place. Portable users must replace their executable manually.
