# Vatrushka 0.8.15

Hawk Desktop Renderer исправление метаданных выпуска.

- Передает неизменяемый тег версии в среду Vite, используемую ловцом ястребов Desktop Renderer.
- Новые события Renderer связаны с опубликованной версией Vatrushka вместо `unknown`.
- Добавляет тест контракта CI для внедрения тега релиза и документирует необходимые переменные упаковки production.
- Не включена миграция PostgreSQL, миграция по ключу Redis, изменение жизненного цикла S3 или конфигурация API runtime.
