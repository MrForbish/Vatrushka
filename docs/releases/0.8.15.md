# Vatrushka 0.8.15

Hawk Desktop Renderer release-metadata correction.

- Passes the immutable release tag into the Vite environment used by the Desktop Renderer Hawk catcher.
- New Renderer events are associated with the published Vatrushka version instead of `unknown`.
- Adds a CI contract test for the release-tag injection and documents the required production packaging variables.
- No PostgreSQL migration, Redis-key migration, S3 lifecycle change, or runtime API configuration is included.
