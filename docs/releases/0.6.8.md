# Vatrushka 0.6.8

Version 0.6.8 is a delivery-only hotfix for native GitLab CI job-token authentication. Application behavior, database schema and observability configuration are unchanged from 0.6.4.

## Fixed

- enables `GLAB_ENABLE_CI_AUTOLOGIN` in the production publication job so `glab` sends `CI_JOB_TOKEN` through the supported `JOB-TOKEN` header;
- removes the unnecessary long-lived release access token from the delivery path;
- policy tests reject production jobs that configure `GITLAB_TOKEN`, preventing the unsupported private-token interpretation of a CI job token.

## Operations

- no PostgreSQL migration, Redis key change, S3 lifecycle change or feature flag is introduced;
- the updater feed and GitLab Release assets are published only after all quality gates and the Windows package job succeed;
- rollback restores the previous updater feed and reverts the merge commit; no database or object-storage rollback is required.
