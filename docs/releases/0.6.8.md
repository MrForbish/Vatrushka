# Vatrushka 0.6.8

Версия 0.6.8 является только поставочной hotfix для нативной GitLab CI аутентификации с использованием токена. Поведение приложения, схема базы данных и конфигурация наблюдаемости остались без изменений по сравнению с версией 0.6.4.

## Исправлено

- включает `GLAB_ENABLE_CI_AUTOLOGIN` в задаче публикации production, чтобы `glab` отправлял `CI_JOB_TOKEN` через поддерживаемый заголовок `JOB-TOKEN`;
- удаляет лишний долговечный токен доступа к выпуску из пути доставки;
- политические проверки отклоняют задачи production, которые настраивают `GITLAB_TOKEN`, предотвращая неподдерживаемую интерпретацию приватного токена задания CI.

## Операции

- не вводится PostgreSQL миграция, Redis изменение ключа, S3 изменение жизненного цикла или feature flag;
- ресурсы updater feed и GitLab Release публикуются только после того, как все контроли качества и задание пакета Windows успешно завершатся;
- откат восстанавливает предыдущую ленту updater и отменяет коммит слияния; откат базы данных или хранилища объектов не требуется.
