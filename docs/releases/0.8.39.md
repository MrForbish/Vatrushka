# Vatrushka 0.8.39

## Изменения продукта

- Одновременные вызовы обновления сессии desktop используют одну и ту же ротацию, предотвращая
случайное повторное использование токена обновления и отзыв сессий семейства.
- Аватары, обложки профиля, иконки серверов и баннеры загружаются напрямую из приватного
S3 с использованием 15-минутных предварительно подписанных URL-адресов GET. Устаревшие настройки CDN игнорируются.
- README включает текущий голос Home и серверный голос screenshots на демонстрационных данных.

## Доставка и миграция

Не требуется миграция базы данных, перемещение объектов, изменения публичного API, изменения разрешений или изменения архитектуры медиа. Токены обновления остаются в Electron main/safeStorage. Приватный бакет и существующие пути вложений сохраняются. Клиенты, которые по-прежнему отображают кэшированные CDN URL, должны обновить свои данные или перезапустить приложение.

Доказательства выпуска предоставляются задачей, сборкой и выпуском MR конвейеров. Обновленные визуальные ссылки Windows объяснены в `docs/testing/2026-09-28-visual-baseline.md`; допуски не были увеличены.

## Откат

Восстановите предшествующего проверенного неизменяемого кандидата API и updater с помощью обертки отката, принадлежащей root. Не перемещайте тег релиза и не перезаписывайте релизные ресурсы. Более старая API снова будет использовать CDN, если её устаревшие настройки останутся включенными; держите эти настройки отключенными, если CDN всё ещё недоступен. Схема отката не требуется. Откат desktop также восстанавливает дефект одновременного обновления.
