# Vatrushka 0.8.3

Версия 0.8.3 исправляет область видимости переменной развертывания production после того, как неизменяемые теги `v0.8.1` и `v0.8.2` безопасно остановились до выполнения любой команды VPS.

## Исправлено

- Production SSH задания явно объявляют защищенную среду `production`.
- GitLab теперь может внедрять переменные файлов SSH, ограниченные областью окружения, без их раскрытия для несвязанных заданий.

## Данные и откат

- Миграция PostgreSQL, Redis или S3 не включена.
- Неудачные предыдущие теги не изменили продукт VPS, мониторинг VPS или канал updater.
- Откат возвращает предыдущий проверенный тег production и ленту updater.
