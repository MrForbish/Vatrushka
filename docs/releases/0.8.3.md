# Vatrushka 0.8.3

Version 0.8.3 repairs production deployment variable scoping after immutable tags `v0.8.1` and `v0.8.2` stopped safely before any VPS command was run.

## Fixed

- Production SSH jobs explicitly declare the protected `production` environment.
- GitLab can now inject the environment-scoped SSH file variables without exposing them to unrelated jobs.

## Data and rollback

- No PostgreSQL, Redis or S3 migration is included.
- The failed earlier tags did not change the product VPS, monitoring VPS or updater feed.
- Rollback remains the previous verified production tag and updater feed.
