# Vatrushka 0.8.27

Production delivery hotfix.

## Fixed

- Restored the root-owned PostgreSQL backup driver: it now imports the Python
  operating-system module required to create the protected backup directory.

## Migration impact

- PostgreSQL migrations: none.
- Redis keys: none.
- S3 lifecycle: none.
- Breaking changes: none.

## Release evidence

The reviewed hotfix publishes immutable delivery candidates. The protected
stable-tag pipeline executes the checksum-bound PostgreSQL backup before
promoting the production candidate.

## Rollback

Use the protected `rollback-production-runtime` job to restore the previous
checksum-verified candidate. No destructive database down migration is
performed.
