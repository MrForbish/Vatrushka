# Vatrushka 0.8.27

Production доставка hotfix.

## Исправлено

- Восстановлен драйвер резервного копирования PostgreSQL, принадлежащий root: теперь он импортирует Python
Требуется модуль операционной системы для создания защищённого каталога резервного копирования.

## Влияние миграции

- PostgreSQL миграции: отсутствуют.
- Redis ключи: нет.
- S3 жизненный цикл: отсутствует.
- Серьезные изменения: отсутствуют.

## Подтверждение релиза

Рассмотренный hotfix публикует неизменяемые кандидаты для доставки. Защищённый стабильный тег pipeline выполняет резервное копирование PostgreSQL, ограниченное контрольной суммой, перед продвижением кандидата production.

## Откат

Используйте защищённую задачу `rollback-production-runtime`, чтобы восстановить предыдущего кандидата с проверкой контрольной суммы. Разрушительная понижающая миграция базы данных не выполняется.
