# Vatrushka 0.8.14

Выпуск с улучшенной надежностью выбора навигации и совместного использования экрана.

- Предотвращает сбой уведомления о недоступности сети из-за неполного офлайн-кэша домашней страницы.
- Сохраняет текущий серверный канал или личный чат стабильными при повторных нажатиях и перемещается из канала перед его удалением.
- Использует диалог подтверждения Vatrushka для удаления канала.
- Делает профиль экранного отображения `2560 × 1440 · 60 FPS` видимо выбираемым над модальным слоем выбора источника.
- Не включена миграция PostgreSQL, миграция с ключом Redis, изменение жизненного цикла S3 или новая конфигурация runtime.
