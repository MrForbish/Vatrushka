# Vatrushka 0.8.14

Navigation and screen-share picker reliability release.

- Prevents an incomplete offline Home cache from crashing the network-unavailable notification.
- Keeps the current server channel or direct conversation stable on repeated clicks and moves away from a channel before it is deleted.
- Uses the Vatrushka confirmation dialog for channel deletion.
- Makes the `2560 × 1440 · 60 FPS` screen-share profile visibly selectable above the source-picker modal layer.
- No PostgreSQL migration, Redis-key migration, S3 lifecycle change, or new runtime configuration is included.
