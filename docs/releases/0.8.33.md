# Vatrushka 0.8.33

Поддержка камеры для голосовых каналов.

## Добавлено

- Роли могут предоставлять `STREAM_VIDEO`; участники, имеющие право, могут публиковать камеру
трек в голосовом канале.
- Станция голосового управления включает выбор камеры вместе с микрофоном и
элементы управления выходным устройством.

## Исправлено

- Надежный Electron renderer теперь получает разрешение на Windows медиа
требуется для захвата с камеры.
- Глобальная голосовая панель возвращается в активный голосовой канал от пользователя и
маршруты настроек сервера.

## Влияние миграции

- PostgreSQL миграции: `0027_stream_video_default_role.sql` добавляет новое
разрешение для существующих ролей `EVERYONE`.
- Redis ключи: нет.
- S3 жизненный цикл: отсутствует.
- Серьезные изменения: отсутствуют.

## Подтверждение релиза

Релиз-кандидат проходит полный необходимый контроль качества, отчет о миграции, проверку установщика Windows и проверки production runtime/наблюдаемости.

## Откат

Используйте защищённую задачу `rollback-production-runtime`, чтобы восстановить предыдущего кандидата с проверенной контрольной суммой. Стабильная версия канала updater продвигается только после успешного выполнения runtime и проверки наблюдаемости.
