# Vatrushka 0.8.33

Camera support for voice channels.

## Added

- Roles can grant `STREAM_VIDEO`; eligible participants can publish a camera
  track in a voice channel.
- The voice dock includes camera-device selection alongside microphone and
  output-device controls.

## Fixed

- The trusted Electron renderer now receives the Windows media permission
  required for camera capture.
- The global voice panel returns to the active voice channel from user and
  server settings routes.

## Migration impact

- PostgreSQL migrations: `0027_stream_video_default_role.sql` adds the new
  permission to existing `EVERYONE` roles.
- Redis keys: none.
- S3 lifecycle: none.
- Breaking changes: none.

## Release evidence

The release candidate runs the full required quality gate, migration report,
Windows installer verification, and production runtime/observability checks.

## Rollback

Use the protected `rollback-production-runtime` job to restore the previous
checksum-verified candidate. The stable updater feed is promoted only after
runtime and observability verification succeeds.
