# Vatrushka 0.8.35

## Product change

Voice-channel camera and screen-share viewing now use one switchable media
stage. The selected stream fills the stage while retaining its aspect ratio;
the stage can be expanded inside the application and closed with Escape.

## Delivery change

This release contains renderer presentation and Storybook verification changes
only. It does not add migrations, change API/shared contracts, alter LiveKit
grants, or modify the deployment topology.

## Rollback

The release pipeline retains the preceding immutable candidate and stable
updater feed. If a regression is found after publication, restore the previous
verified candidate through the root-owned rollback wrapper; do not overwrite
the immutable tag or release.
