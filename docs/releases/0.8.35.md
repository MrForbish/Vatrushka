# Vatrushka 0.8.35

## Изменение продукта

Просмотр камеры голосового канала и общего экрана теперь использует одну переключаемую медиасцену. Выбранный поток заполняет сцену, сохраняя свои пропорции; сцену можно развернуть внутри приложения и закрыть клавишей Escape.

## Изменение доставки

Этот выпуск содержит только изменения презентации renderer и проверки Storybook. Он не добавляет миграций, не изменяет контракты API/shared, не изменяет гранты LiveKit и не модифицирует топологию развертывания.

## Откат

Релиз pipeline сохраняет предшествующего неизменяемого кандидата и стабильный канал updater. Если после публикации будет обнаружена регрессия, восстановите предыдущего проверенного кандидата через обертку отката, принадлежащую корню; не перезаписывайте неизменяемую метку или релиз.
