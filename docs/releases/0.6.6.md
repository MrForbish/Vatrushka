# Vatrushka 0.6.6

Версия 0.6.6 является только поставкой hotfix для детерминированной упаковки Windows. Поведение приложения, схема базы данных и конфигурация наблюдаемости не изменились по сравнению с 0.6.4.

## Исправлено

- скачивает официальную контрольную сумму манифеста Electron с повторными попытками `curl` вместо того, чтобы полагаться на нестабильный путь загрузки Node;
- проверяет архив Electron, winCodeSign, ресурсы NSIS и NSIS по фиксированным значениям SHA-256 перед упаковкой;
- передаёт проверенный локальный Electron ZIP непосредственно в `electron-builder` и кэширует проверенные наборы инструментов сборки в GitLab CI.

## Операции

- нет PostgreSQL миграции, Redis изменения ключа, S3 изменения жизненного цикла или feature flag введено;
- ресурсы поставки updater и выпуска GitLab публикуются только после того, как все существующие контрольные точки качества и задание пакета Windows успешно выполнены;
- откат возвращает канал updater и развертывание API/Caddy к версии 0.6.3; отдельный модуль наблюдаемости Compose можно остановить без удаления томов.
