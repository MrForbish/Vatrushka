# Vatrushka 0.6.6

Version 0.6.6 is a delivery-only hotfix for deterministic Windows packaging. Application behavior, database schema and observability configuration are unchanged from 0.6.4.

## Fixed

- downloads the official Electron checksum manifest with retrying `curl` instead of relying on the unstable Node download path;
- verifies the Electron archive, winCodeSign, NSIS and NSIS resources against pinned SHA-256 values before packaging;
- passes the verified local Electron ZIP directly to `electron-builder` and caches verified builder toolsets in GitLab CI.

## Operations

- no PostgreSQL migration, Redis key change, S3 lifecycle change or feature flag is introduced;
- the updater feed and GitLab Release assets are published only after all existing quality gates and the Windows package job succeed;
- rollback returns the updater feed and API/Caddy deployment to 0.6.3; the separate observability Compose can be stopped without removing volumes.
