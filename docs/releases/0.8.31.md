# Vatrushka 0.8.31

Экстренный выпуск восстановления контекста микрофона.

## Исправлено

- Соединение с голосом больше не прекращается, когда LiveKit ещё не присоединился
Контекст WebAudio к недавно опубликованной дорожке с микрофона.
- Локальное усиление микрофона остаётся необязательным улучшением: если его WebAudio
контекст недоступен, микрофон продолжает передавать без обработки усиления вместо того, чтобы отображать внутреннюю ошибку браузера.

## Влияние миграции

- PostgreSQL миграции: отсутствуют.
- Redis ключи: нет.
- S3 жизненный цикл: отсутствует.
- Серьезные изменения: отсутствуют.

## Подтверждение релиза

hotfix запускает desktop typecheck, целевые регрессионные тесты медиа, desktop сборку и проверку бюджета пакета перед защищенным основным слиянием. Защищенный тег pipeline продвигает неизменяемый кандидат и публикует updater только после runtime и проверки наблюдаемости.

## Откат

Используйте защищённую задачу `rollback-production-runtime`, чтобы восстановить предыдущего кандидата с проверкой контрольной суммы. Стабильная версия канала updater публикуется только после успешного прохождения проверок runtime и наблюдаемости.
