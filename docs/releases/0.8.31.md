# Vatrushka 0.8.31

Emergency microphone-context recovery release.

## Fixed

- Voice connection no longer fails when LiveKit has not yet attached a
  WebAudio context to a newly published microphone track.
- Local microphone gain remains an optional enhancement: if its WebAudio
  context is unavailable, the microphone continues to publish without gain
  processing instead of surfacing an internal browser error.

## Migration impact

- PostgreSQL migrations: none.
- Redis keys: none.
- S3 lifecycle: none.
- Breaking changes: none.

## Release evidence

The hotfix runs the desktop typecheck, targeted media regression tests, desktop
build and bundle-budget check before the protected main merge. The protected tag
pipeline promotes the immutable candidate and publishes the updater only after
runtime and observability verification.

## Rollback

Use the protected `rollback-production-runtime` job to restore the previous
checksum-verified candidate. The stable updater feed is published only after the
runtime and observability checks succeed.
