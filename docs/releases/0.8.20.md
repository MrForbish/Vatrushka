# Vatrushka 0.8.20

Небольшой выпуск технического обслуживания после миграции набора V2 UI.

## Изменено

- Удаляет подтверждённый неиспользуемый предварительный просмотр устаревшей аутентификации, преимущества и отзывчивый CSS.
- Сохраняет активные процессы аутентификации и профиля, API/общие контракты,
разрешения, WebSocket/переподключение, LiveKit/медиа и Electron граница предварительной загрузки.

## Влияние миграции

- PostgreSQL миграции: нет.
- Redis ключи: нет.
- S3 жизненный цикл: отсутствует.
- Конфигурация Runtime: отсутствует.

## Подтверждение релиза

- Очистка MR !127 прошла проверку политики, верификацию, поведение desktop и проверку на визуальные регрессии.
- Подготовка к выпуску повторно проверяет согласованность версий, политику, lint, проверки типов,
тесты взаимодействия Storybook и тесты visual regression.

## Откат

Отмените слияние релиза из `main` и разверните предыдущий неизменяемый тег. Откат базы данных, контрактов Redis, S3, API, аутентификации или медиа не требуется.
