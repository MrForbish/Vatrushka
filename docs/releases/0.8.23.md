# Vatrushka 0.8.23

Production доставка портативность выпуск.

## Изменено

- Использует синтаксис проверки контрольной суммы, совместимый с BusyBox, в заданиях с защищёнными тегами.
- Нормализует безопасный для CRLF SSH приватный ключ и известный материал хоста перед выполняемой production проверкой.

## Влияние миграции

- PostgreSQL миграции: нет.
- Redis ключи: нет.
- S3 жизненный цикл: отсутствует.
- Серьезные изменения: отсутствуют.

## Подтверждение релиза

Защищённый тег разрешает неизменяемые кандидаты артефактов, проверяет их контрольные суммы, выполняет production предполётную проверку и только затем открывает стабильный updater канал после развертывания и проверки Наблюдателем.

## Откат

Используйте защищённую задачу `rollback-production-runtime` для восстановления предыдущего кандидата, проверенного контрольной суммой. Понижение версии базы данных не выполняется.
