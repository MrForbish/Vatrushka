# Vatrushka 0.8.23

Production delivery portability release.

## Changed

- Uses the BusyBox-compatible checksum-validation syntax in protected tag jobs.
- Normalizes CRLF-safe SSH private-key and known-host material before production preflight.

## Migration impact

- PostgreSQL migrations: none.
- Redis keys: none.
- S3 lifecycle: none.
- Breaking changes: none.

## Release evidence

The protected tag resolves immutable candidate artifacts, validates their checksums,
performs production preflight, and only then exposes the stable updater feed after
deployment and Observer verification.

## Rollback

Use the protected `rollback-production-runtime` job to restore the prior
checksum-verified candidate. No database down migration is performed.
