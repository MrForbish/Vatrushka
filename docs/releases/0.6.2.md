# Vatrushka 0.6.2

Версия 0.6.2 является срочным desktop выпуском, который восстанавливает вход по паролю и 2FA после того, как обновление 0.6.1 было упаковано с использованием резервного решения разработки API.

## Исправлено

- установленный клиент Windows нацелен на `https://api.myvatrushka.ru` вместо `http://localhost:3000`;
- Рабочие процессы production и кандидат на выпуск предоставляют явный desktop API URL;
- Команда упаковки Windows теперь завершает работу с ошибкой до публикации, если production API URL отсутствует, локальный или отсутствует в скомпилированном пакете renderer.

## Операции

Нет миграций базы данных или API. Сборка с `VITE_PUBLIC_API_BASE_URL=https://api.myvatrushka.ru`, проверьте упакованный `app.asar`, затем опубликуйте установщик версии 0.6.2 и блок-карту перед атомарной заменой `latest.yml`. Не повторно публикуйте 0.6.1 под той же версией.
