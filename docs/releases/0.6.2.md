# Vatrushka 0.6.2

Version 0.6.2 is an urgent desktop release that restores password and 2FA login after the 0.6.1 update artifact was packaged with the development API fallback.

## Fixed

- the installed Windows client targets `https://api.myvatrushka.ru` instead of `http://localhost:3000`;
- production and release-candidate workflows provide an explicit desktop API URL;
- the Windows packaging command now fails before publication when the production API URL is missing, local, or absent from the compiled renderer bundle.

## Operations

There are no database or API migrations. Build with `VITE_PUBLIC_API_BASE_URL=https://api.myvatrushka.ru`, verify the packaged `app.asar`, then publish the 0.6.2 installer and blockmap before atomically replacing `latest.yml`. Do not republish 0.6.1 under the same version.
