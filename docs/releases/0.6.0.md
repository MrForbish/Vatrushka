# Vatrushka 0.6.0

Версия 0.6.0 завершает дорожную карту сообщений, настроек, присутствия и уведомлений поверх постоянных серверов и каналов.

## Изменения, видимые пользователю

- История канонического сервера и личных сообщений теперь поддерживает пагинацию вверх, оптимистичное повторное отправление, редактирование, пометки об удалении, сообщения только с вложениями, аутентифицированный предварительный просмотр изображений, реакции и навигацию к первому непрочитанному сообщению.
- Структурированные упоминания пользователя, роли и `@everyone` проверяются API и остаются корректными после переименований.
- Прямые сообщения отображают состояние отправки, доставки и прочтения; повторное подключение в реальном времени синхронизирует пропущенные сообщения и позиции прочтения.
- Настройки уведомлений доступны на уровне пользователя, сервера и разговоров, включая тихие часы, отключение звука windows, конфиденциальность предварительного просмотра и строгую DND блокировку доставки.
- Настройки пользователя охватывают профиль/аватар/имя пользователя/биографию, присутствие, аудиоустройства, конфиденциальность/блокировку, пароль/двухфакторную аутентификацию, сессии, электронную почту, экспорт и отложенную анонимизацию аккаунта.
- Настройки сервера охватывают внешний вид, участников, роли, каналы, ссылки-приглашения, модерацию, журнал аудита, передачу владения, архивирование и окончательное удаление.
- Присутствие, поддерживаемое Redis, работает во время одновременных сеансов desktop и учитывает невидимый статус и правила конфиденциальности.
- updater остаётся скрытым, когда выпуск отсутствует, и откладывает перезапуск, пока активна голосовая связь.

## Платформа и операции

- Аутентифицированная доставка WebSocket использует Redis Pub/Sub и PostgreSQL транзакционный outbox.
- Приватные вложения Timeweb S3 имеют долговечные задачи очистки, повторные попытки и триггер базы данных, который также охватывает каскадное удаление.
- `GET /metrics` предоставляет технические Prometheus метрики для обмена сообщениями, WebSocket, outbox, Redis и уведомлений.
- Сборка Windows production включает маршрутизируемые настройки и присутствие и нацелена на `https://api.myvatrushka.ru`.

## Проверка

- ESLint и TypeScript typecheck.
- Общие, API, renderer и реальные PostgreSQL/Redis интеграционные тесты.
- тесты взаимодействия/доступности Storybook и Windows visual regression.
- Electron E2E, проверка цепочки миграции, production бюджеты сборки и пакетов.

## Развертывание

Сделайте резервную копию PostgreSQL перед развертыванием. Примените полную цепочку миграции через `0024_server_member_aliases`, проверьте Redis и приватный S3 канареечный, затем проверьте `/health/live` и `/health/ready`.

Опубликуйте `Vatrushka-Setup-0.6.0-x64.exe` и его блок-карту перед атомарной заменой `latest.yml`. Установленные клиенты NSIS версии 0.5.0 могут обновиться на месте; неподписанный пакет всё ещё может показывать предупреждение о репутации Windows.
