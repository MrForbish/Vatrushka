# Vatrushka 0.8.2

Version 0.8.2 repairs the production delivery runner path after the immutable `v0.8.1` tag could not start its product deployment job.

## Fixed

- Production SSH deployment jobs now pull `alpine:3.22` through GitLab Dependency Proxy instead of Docker Hub directly.
- This prevents Docker Hub anonymous pull rate limits from blocking deployment before any product command is run.

## Data and rollback

- No PostgreSQL, Redis or S3 migration is included.
- `v0.8.1` did not reach product or monitoring deployment; it remains an immutable historical tag.
- Rollback remains the prior verified production tag and updater feed.
