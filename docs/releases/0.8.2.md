# Vatrushka 0.8.2

Версия 0.8.2 исправляет путь доставочного раннера production, после того как неизменяемый тег `v0.8.1` не смог запустить задание по развертыванию продукта.

## Исправлено

- Задачи развертывания Production SSH теперь получают `alpine:3.22` через Dependency Proxy GitLab, вместо того чтобы напрямую через Docker Hub.
- Это предотвращает блокировку развертывания из-за анонимных ограничений скорости pull на Docker Hub до выполнения какой-либо команды продукта.

## Данные и откат

- Миграция PostgreSQL, Redis или S3 не включена.
- `v0.8.1` не достиг развертывания продукта или мониторинга; это остаётся неизменяемой исторической меткой.
- Откат возвращает предыдущий проверенный тег production и канал updater.
