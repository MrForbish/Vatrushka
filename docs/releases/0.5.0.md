# Vatrushka 0.5.0

Версия 0.5.0 заменяет прежний экран приветствия на персональную панель Home и завершает удаление устаревших автономных комнат. Выпуск сохраняет постоянные серверы и их текстовые/голосовые каналы как единственную модель сотрудничества.

## Изменения, видимые пользователю

- Теперь на главной отображаются Продолжить, Активные пространства, Недавняя активность, готовность аудио, ввод в эксплуатацию и текущий профиль в одном адаптивном рабочем пространстве.
- Данные панели управления кэшируются локально и обновляются при изменении состояния сервера, канала, сообщения и присутствия.
- Готовность аудио использует выбранный микрофон Windows и сообщает о разрешениях и уровне входного сигнала без открытия второго потока захвата во время активного звонка.
- Присутствие голоса, перемещения участников, текстовые уведомления, сообщения только с вложениями, предварительный просмотр изображений и расширенный выбор реакций интегрированы с постоянными каналами сервера.
- Ручное присоединение по коду UI и отдельные потоки комнат больше недоступны.
- Сервер и прямые сообщения теперь используют канонические PostgreSQL беседы с аутентифицированной доставкой WebSocket, Redis Pub/Sub, транзакционную outbox и HTTP сверку повторного подключения.
- Прямые сообщения показывают отправленные/доставленные/прочитанные, оптимистичное повторное отправление и навигацию к первому непрочитанному; настройки уведомлений поддерживают диапазоны пользователя, сервера и беседы с строгим DND.
- Настройки сервера/пользователя поддерживаются реальными данными API, включая внешний вид, модерацию, аудит, профиль/аватар/имя пользователя/биографию, конфиденциальность, блокировку и жизненный цикл аккаунта.

## Проверка

- TypeScript typecheck и ESLint.
- Общие модульные тесты API и renderer.
- Storybook тесты взаимодействия и доступности.
- Windows visual regression для состояний дома, профиля, аутентификации, голосовых функций, медиа и безопасности.
- Electron E2E, проверка согласованности миграции и проверки бюджета пакета production.

## Развертывание

Этот выпуск применяет полную проверенную цепочку миграции через `0022_square_luminals`. `0012_remove_legacy_rooms_contract` намеренно удаляет только устаревшие автономные комнаты; последующие добавочные миграции добавляют активность Home, настройки, идентификацию, присутствие, каноническую систему сообщений, предпочтения уведомлений, outbox и долговременные задания очистки S3. Постоянные серверные каналы и `channel_screen_share_leases` остаются нетронутыми.

Создайте резервную копию PostgreSQL перед обновлением API. Постройте и запустите стек production Compose, проверьте `/health/ready`, затем опубликуйте `Vatrushka-Setup-0.5.0-x64.exe` и его блок-карту перед атомарной заменой `latest.yml`. Установленные клиенты версии 0.4.x могут обновляться на месте; портативные пользователи должны заменить исполняемый файл вручную.
