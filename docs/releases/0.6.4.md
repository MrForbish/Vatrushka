# Vatrushka 0.6.4

Версия 0.6.4 завершает приватный срез наблюдаемости production и переносит канонический процесс сборки и выпуска на самостоятельно управляемые GitLab CI.

## Добавлено

- метрики с низкой кардинальностью API запроса, задержки, готовности и Node.js runtime;
- приватные сервисы Prometheus и Grafana с предоставленным источником данных и обзорная панель production;
- экспортеры node, cAdvisor, PostgreSQL, Redis и blackbox;
- 14 первоначальных правил оповещений для доступности/задержки/ошибок API, обмена сообщениями outbox, Redis, PostgreSQL, диска хоста и истечения срока действия TLS;
- операционный runbook, охватывающий частный доступ, хранение, проверку и откат.

## Изменено

- GitLab является каноническим репозиторием, запросом на слияние и платформой CI/CD;
- Работы по проверке/интеграции Linux и работы Windows Electron/визуального/пакетного исполнения запускаются на самостоятельно управляемых исполнителях проекта;
- Изображения экспортера Prometheus и Redis используют их официальный реестр Quay, чтобы избежать ограничения скорости Hub Docker;
- публичный Caddy `/metrics` маршрут возвращает `404`; Prometheus напрямую обрабатывает точку доступа API loopback.

## Операции

- не вводится PostgreSQL миграция, Redis миграция ключа, S3 изменение жизненного цикла или нарушение API контракта;
- создайте `infra/observability/.env.observability` с случайным паролем администратора Grafana перед запуском стека;
- не открывайте порты мониторинга в UFW или в фаерволе Timeweb; используйте задокументированный туннель SSH;
- следите за первыми семью днями, прежде чем ужесточать пороговые значения или настраивать внешний приемник технических уведомлений;
- откат останавливает только отдельный проект наблюдаемости Compose и сохраняет его именованные тома, если они явно не удалены.
