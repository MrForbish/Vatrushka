# Vatrushka 0.8.19

Второй production срез комплекта V2 UI.

- Согласует рабочую среду live Server и личных сообщений с утвержденным комплектом UI:
более плотная четырёхрельсовая схема, этап сообщения и композитор, поиск по реальному разговору, заголовок разговора с учётом аватара и компактное действие уведомления.
- Сохраняет существующий API, совместные контракты, модель разрешений, аутентификацию,
WebSocket/переподключение, LiveKit/медиа и границы предзагрузки Electron без изменений.
- Обновляет затронутые базовые визуальные показатели Storybook и сохраняет охват взаимодействия
для виртуализированных сообщений и действий с прямыми сообщениями.

## Влияние миграции

- PostgreSQL миграции: нет.
- Redis ключи: нет.
- S3 жизненный цикл: отсутствует.
- Runtime конфигурация: отсутствует.

## Подтверждение релиза

- UI Сообщение комплекта MR !119 прошло требуемое pipeline перед подготовкой к выпуску.
- Подготовка к выпуску проверяет согласованность версий, политику, lint, типовые проверки,
тесты взаимодействия Storybook и тесты visual regression.

## Откат

Отмените слияние релиза из `main` и разверните предыдущий неизменяемый тег. Откат базы данных, контрактов Redis, S3, API, аутентификации или медиа не требуется.
