# Vatrushka 0.8.6

Восстанавливает надежную оперативную видимость для присутствия голоса и совместного использования экрана.

- API обновляет `voice_active_sessions` из голосового присутствия Redis и `screen_share_active_sessions` из действительных аренды PostgreSQL для каждого внутреннего сканирования Prometheus.
- Prometheus уведомляет, когда сведения о телеметрии продукта не поступают через частный путь Alloy/WireGuard в течение пяти минут.
- Миграция PostgreSQL, с ключом Redis или S3 не включена.

## Проверка

1. Подтвердите, что `up{job="vatrushka-api"} == 1` и `vatrushka_build_info` присутствуют в центральном Prometheus.
2. Подключите тестового пользователя к голосовому каналу и дождитесь одного интервала сканирования.
3. Подтвердите, что `voice_active_sessions` соответствует снимку состояния голосового сервера.
4. Начать и остановить демонстрацию экрана; подтвердите, что `screen_share_active_sessions` следует активной аренде.
