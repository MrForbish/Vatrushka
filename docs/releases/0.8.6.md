# Vatrushka 0.8.6

Restores reliable operational visibility for voice presence and screen sharing.

- The API refreshes `voice_active_sessions` from Redis voice presence and `screen_share_active_sessions` from valid PostgreSQL leases for every internal Prometheus scrape.
- Prometheus alerts when no product telemetry arrives through the private Alloy/WireGuard path for five minutes.
- No PostgreSQL, Redis-key, or S3 migration is included.

## Verification

1. Confirm `up{job="vatrushka-api"} == 1` and `vatrushka_build_info` are present in central Prometheus.
2. Connect a test user to a voice channel and wait for one scrape interval.
3. Confirm `voice_active_sessions` matches the server voice-state snapshot.
4. Start and stop a screen share; confirm `screen_share_active_sessions` follows the active lease.
