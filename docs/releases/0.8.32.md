# Vatrushka 0.8.32

Выпуск настроек аудио и доставки медиа.

## Изменено

- Объемы ввода, вывода и уведомлений являются независимыми локальными настройками с
значение по умолчанию 50%; проверки вывода и уведомлений используют разные Vatrushka сигналы.
- Выбранные устройства ввода/вывода и их локальные уровни громкости сохраняются
в течение desktop перезапусков.
- Профиль и серверные медиа могут быть переданы через настроенный частный
CDN использует короткоживущие URL-адреса безопасных токенов.

## Исправлено

- Повторное подключение больше не уменьшает усиление удаленного участника вдвое перед сохранением вывода
настройки применены.
- Профиль и изображения сервера сохраняют своё последнее успешное отображение, пока
обновлённая подписанная URL загружается, чтобы избежать временного мерцания аватара/обложки.
- Тестирование микрофона всегда можно явно остановить.

## Влияние миграции

- PostgreSQL миграции: нет.
- Redis ключи: нет.
- S3 жизненный цикл: отсутствует.
- Серьезные изменения: отсутствуют.

## Подтверждение релиза

Релиз-кандидат проходит полный необходимый контроль качества, отчет о миграции, проверку установщика Windows и проверки production runtime/наблюдаемости.

## Откат

Используйте защищённую задачу `rollback-production-runtime`, чтобы восстановить предыдущего кандидата с проверенной контрольной суммой. Стабильная версия канала updater обновляется только после успешного выполнения runtime и проверки наблюдаемости.
