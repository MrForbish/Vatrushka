# Vatrushka 0.8.32

Audio-settings and media-delivery release.

## Changed

- Input, output and notification volumes are independent local settings with
  a 50% default; output and notification checks use distinct Vatrushka cues.
- The selected input/output devices and their local volume levels persist
  across desktop restarts.
- Profile and server media can be delivered through the configured private
  CDN origin using short-lived Secure Token URLs.

## Fixed

- Reconnect no longer halves remote participant gain before persisted output
  settings are applied.
- Profile and server images retain their last successful render while a
  refreshed signed URL is loading, avoiding transient avatar/cover flicker.
- Microphone testing can always be stopped explicitly.

## Migration impact

- PostgreSQL migrations: none.
- Redis keys: none.
- S3 lifecycle: none.
- Breaking changes: none.

## Release evidence

The release candidate runs the full required quality gate, migration report,
Windows installer verification and production runtime/observability checks.

## Rollback

Use the protected `rollback-production-runtime` job to restore the previous
checksum-verified candidate. The stable updater feed is updated only after
runtime and observability verification succeeds.
