# Vatrushka 0.8.18

The first production slice of the V2 UI Kit.

- Establishes the shared visual foundations, global application shell, system toolbar,
  profile card, overlays, avatar and community-logo primitives.
- Refreshes Home as a live personal dashboard using the existing active-space and
  friends-in-game data. It does not substitute static mock content for product flows.
- Keeps existing authentication, permission, WebSocket/reconnect, LiveKit/media,
  API, shared contracts and Electron preload boundaries unchanged.
- Makes AppShell visual regression scenarios deterministic while retaining their
  separate interaction coverage.

## Migration impact

- PostgreSQL migrations: none.
- Redis keys: none.
- S3 lifecycle: none.
- Runtime configuration: none.

## Release evidence

- UI Kit foundations MR !115 and Home MR !116 passed their required pipelines.
- Local release-preparation validation covers version consistency, policy, lint,
  type checks, Storybook interaction tests and visual regression tests.

## Rollback

Revert the release merge from `main` and redeploy the previous immutable tag.
No database, Redis, S3, API contract, authentication or media rollback is required.
