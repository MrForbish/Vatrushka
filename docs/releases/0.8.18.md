# Vatrushka 0.8.18

Первый production срез комплекта V2 UI.

- Устанавливает общие визуальные основы, глобальную оболочку приложения, системную панель инструментов,
карточка профиля, оверлеи, аватар и элементы логотипа сообщества.
- Обновляет Дом как живую персональную панель с использованием существующего активного пространства и
данные друзей в игре. Это не заменяет статический макетный контент для продуктовых потоков.
- Сохраняет существующую аутентификацию, разрешение, WebSocket/повторное подключение, LiveKit/медиа,
API, совместные контракты и границы предварительной загрузки Electron без изменений.
- Делает сценарии AppShell visual regression детерминированными, при этом сохраняя их
отдельное покрытие взаимодействия.

## Влияние миграции

- PostgreSQL миграции: нет.
- Redis ключи: нет.
- S3 жизненный цикл: отсутствует.
- Runtime конфигурация: отсутствует.

## Подтверждение релиза

- UI Фундаменты комплектов MR !115 и Дом MR !116 прошли свои обязательные трубопроводы.
- Местная проверка подготовки к выпуску охватывает согласованность версий, политику, lint,
проверки типов, Storybook тесты взаимодействия и visual regression тесты.

## Откат

Отмените слияние релиза из `main` и разверните предыдущий неизменяемый тег. Откат базы данных, контрактов Redis, S3, API, аутентификации или медиа не требуется.
