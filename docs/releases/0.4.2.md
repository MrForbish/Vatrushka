# Vatrushka 0.4.2

Version 0.4.2 simplifies Home navigation and adds lightweight voice-channel presence feedback. It does not add a database migration or change the public API contract.

## User-visible changes

- The redundant middle navigation column is removed from Home. Server creation/joining remains in the left workspace rail, while security and logout are available in the top bar.
- Double-clicking a voice channel name connects to it while preserving the server and channel lists.
- Soft ascending/descending cues play when the current user or a remote participant joins/leaves a voice channel.
- Presence cues follow the selected output device where Chromium supports output routing.

## Verification

- renderer: silent participant baseline, remote join/leave diffs, Home shell structure and double-click voice connection;
- Storybook: interaction and accessibility suite;
- Electron: authenticated shell and media-device regressions;
- Windows visual baseline: simplified Home layout;
- database migration and renderer bundle budget gates.

## Rollout

Build and publish `Vatrushka-Setup-0.4.2-x64.exe` plus its blockmap before atomically replacing `latest.yml`. Installed 0.4.0 and 0.4.1 clients can update in place. Portable users must replace their executable manually.
