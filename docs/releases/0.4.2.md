# Vatrushka 0.4.2

Версия 0.4.2 упрощает навигацию по домашней странице и добавляет лёгкую обратную связь о присутствии в голосовом канале. Она не добавляет миграцию базы данных и не изменяет публичный контракт API.

## Изменения, видимые пользователю

- Избыточная средняя навигационная колонка удалена с главной страницы. Создание/подключение к серверу остается в левой рабочей панели, а функции безопасности и выхода доступны в верхней панели.
- Двойной щелчок по названию голосового канала подключает к нему, при этом сохраняя списки серверов и каналов.
- Мягкие сигналы повышения/понижения воспроизводятся, когда текущий пользователь или удалённый участник присоединяется к голосовому каналу или покидает его.
- Сигналы присутствия следуют за выбранным устройством воспроизведения, если Chromium поддерживает маршрутизацию вывода.

## Проверка

- renderer: базовый уровень для молчаливого участника, различия при удалённом присоединении/выходе, структура главного интерфейса и соединение голосом по двойному щелчку;
- Storybook: набор для взаимодействия и доступности;
- Electron: проверка регрессий защищённого оболочки и медиапротоколов;
- Windows визуальная база: упрощённая планировка дома;
- миграция базы данных и renderer процесс проверки бюджета пакета.

## Внедрение

Соберите и опубликуйте `Vatrushka-Setup-0.4.2-x64.exe` вместе с его блок-картой перед атомарной заменой `latest.yml`. Установленные клиенты версий 0.4.0 и 0.4.1 могут обновиться на месте. Пользователи портативной версии должны заменить исполняемый файл вручную.
