# Vatrushka 0.6.10

Version 0.6.10 delivers prompt automatic update discovery and removes the Windows release build's runtime dependency on GitHub.

## Fixed

- checks the stable update feed immediately after startup, every 15 minutes, after app focus, and after Windows resume;
- downloads the locked Electron, NSIS and signing helper archives from the private GitLab Generic Package Registry using `CI_JOB_TOKEN`;
- validates every toolchain archive against the repository lock before use;
- separates packaging caches from Electron E2E and visual-regression caches.

## Release history

The immutable `v0.6.9` tag did not publish a GitLab Release or update feed because its Windows packaging job could not reach GitHub. Version 0.6.10 supersedes that failed publication attempt without moving or overwriting the tag.

## Operations

- no PostgreSQL migration, Redis key change, S3 lifecycle change or feature flag is introduced;
- rollback restores the previous updater metadata and reverts the merge commit; server data is unchanged.
