# Vatrushka 0.6.10

Версия 0.6.10 обеспечивает быструю автоматическую проверку обновлений и удаляет зависимость runtime от GitHub в сборке выпуска Windows.

## Исправлено

- проверяет канал стабильных обновлений сразу после запуска, каждые 15 минут, после фокусировки приложения и после возобновления Windows;
- скачивает заблокированные архивы Electron, NSIS и помощника подписи из частного реестра Generic Package Registry GitLab с использованием `CI_JOB_TOKEN`;
- проверяет каждый архив инструментальной цепочки на соответствие блокировке репозитория перед использованием;
- разделяет кэши упаковки от Electron E2E и кэшей визуальной регрессии.

## История выпусков

Неизменяемый тег `v0.6.9` не опубликовал выпуск или поток обновлений GitLab, потому что его задача упаковки Windows не смогла достичь GitHub. Версия 0.6.10 заменяет эту неудачную попытку публикации без перемещения или перезаписи тега.

## Операции

- не вводится PostgreSQL миграция, Redis изменение ключа, S3 изменение жизненного цикла или feature flag;
- откат восстанавливает предыдущие метаданные updater и возвращает объединяющий коммит; данные на сервере остаются без изменений.
