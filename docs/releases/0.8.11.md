# Vatrushka 0.8.11

## Исправлено

- Исправлены селекторы LogQL Grafana для значения фильтра «Все» и заменён вводящий в заблуждение псевдовременной штамп компактора Loki.
- Улучшены подписи на панели наблюдаемости и поведение при отсутствии данных для лимитов контейнеров, панелей ошибок Redis и HTTP.
- Восстановлено отображение загруженного профиля, аватара сервера и обложки на навигации, в настройках и на карточках рабочего пространства.
- Исправлена первоначальная прокрутка текстового канала и уточнено оформление полос прокрутки справки и приложения.
- Добавлены безопасные диагностики Hawk для доступности репортера и попыток отправки при запуске.

## Заметки по развертыванию

- Нет PostgreSQL миграций, Redis ключевых миграций или S3 изменений жизненного цикла.
- Агент наблюдаемости продукта воссоздаётся во время развертывания только тогда, когда существует его оператор, управляемый `infra/observability/agents/.env.agent`.
- Откат: отмените коммит выпуска и опубликуйте новый патч-релиз. Изменения в канале updater происходят только после полного успешного production pipeline.
