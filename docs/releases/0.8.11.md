# Vatrushka 0.8.11

## Fixed

- Corrected Grafana LogQL selectors for the "All" filter value and replaced the misleading Loki compactor pseudo-timestamp.
- Improved observability dashboard labels and no-data behaviour for container limits, Redis and HTTP error-rate panels.
- Restored uploaded profile, server avatar and cover rendering across navigation, settings and workspace cards.
- Corrected initial text-channel scrolling and refined Help and application scrollbar styling.
- Added safe Hawk diagnostics for reporter availability and startup submission attempts.

## Deployment notes

- No PostgreSQL migrations, Redis key migrations or S3 lifecycle changes.
- The product observability agent is recreated during deployment only when its operator-managed `infra/observability/agents/.env.agent` exists.
- Rollback: revert the release commit and publish a new patch release. The updater feed changes only after a complete successful production pipeline.
