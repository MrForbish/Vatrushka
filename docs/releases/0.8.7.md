# Vatrushka 0.8.7

Обеспечивает применение конфигурации наблюдаемости из релиза работающей платформой.

- Развертывание системы наблюдаемости воссоздает связанные с конфигурацией службы Compose после проверки, поэтому обновленные правила Prometheus и настройка панели управления не остаются на диске без загрузки.
- Тома, данные S3, `.env.observability`, секреты и локальные переопределения Compose остаются нетронутыми.
- Нет включенной миграции жизненного цикла PostgreSQL, Redis-ключа или S3.
