# Vatrushka 0.8.7

Ensures observability configuration from a release is applied by the running platform.

- The observability deployment recreates config-bound Compose services after validation, so updated Prometheus rules and dashboard provisioning are not left on disk without being loaded.
- Volumes, S3 data, `.env.observability`, secrets and local Compose overrides remain untouched.
- No PostgreSQL, Redis-key, or S3 lifecycle migration is included.
