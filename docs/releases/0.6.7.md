# Vatrushka 0.6.7

Версия 0.6.7 является только поставкой hotfix для публикации релиза GitLab. Поведение приложения, схема базы данных и конфигурация наблюдаемости не изменились по сравнению с 0.6.4.

## Исправлено

- тег pipeline использует защищённую и замаскированную переменную `GITLAB_RELEASE_TOKEN` для API GitLab Releases и Generic Packages;
- задача production проверяет, что токен выпуска доступен перед загрузкой updater и артефактов выпуска;
- тесты политики репозитория отклоняют задание production, которое переходит на `CI_JOB_TOKEN`, которое не может публиковать релизы в этом проекте GitLab.com.

## Операции

- не вводится PostgreSQL миграция, Redis изменение ключа, S3 изменение жизненного цикла или feature flag;
- ресурсы updater feed и GitLab Release публикуются только после того, как все контрольные точки качества и задание пакета Windows успешно завершатся;
- откат восстанавливает предыдущую updater ленту и API/Caddy развертывание; стек наблюдения является независимым и его останавливать не нужно.
