# Vatrushka 0.6.7

Version 0.6.7 is a delivery-only hotfix for GitLab Release publication. Application behavior, database schema and observability configuration are unchanged from 0.6.4.

## Fixed

- the tag pipeline uses the protected and masked `GITLAB_RELEASE_TOKEN` variable for the GitLab Releases and Generic Packages APIs;
- the production job validates that the release token is available before uploading the updater and release artifacts;
- repository policy tests reject a production job that falls back to `CI_JOB_TOKEN`, which cannot publish releases in this GitLab.com project.

## Operations

- no PostgreSQL migration, Redis key change, S3 lifecycle change or feature flag is introduced;
- the updater feed and GitLab Release assets are published only after all quality gates and the Windows package job succeed;
- rollback restores the previous updater feed and API/Caddy deployment; the observability stack is independent and does not need to be stopped.
