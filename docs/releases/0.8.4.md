# Vatrushka 0.8.4

Production уплотнение развертывания после того, как `v0.8.3` достиг продукта VPS, но не смог записать в расположение runtime с правами root.

- Команды развертывания используют неинтерактивный sudo, который работает для настроенного пользователя развертывания и закрыто не выполняется, если привилегии недоступны.
- Доставка наблюдаемости использует текущую конечную точку мониторинга VPS и её закреплённый ключ хоста SSH.
- Нет базы данных, миграция Redis или S3 не включена.
