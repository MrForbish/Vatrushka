# Vatrushka 0.6.1

Version 0.6.1 publishes the settings, messaging and screen-sharing reliability work completed after 0.6.0.

## Highlights

- fixes canonical text-channel history loading and realtime message deletion;
- completes routed server settings, profile aliases and presence synchronization;
- stabilizes repeated screen sharing, mandatory protected system audio, quality selection and fullscreen viewing;
- moves participant and stream volume controls into context menus and improves overlay behavior;
- refreshes Windows visual-regression baselines and keeps the updater hidden when no newer release exists.

## Operations

The API rollout applies additive migration `0024_server_member_aliases`. Create a PostgreSQL backup before replacing the API image, then verify PostgreSQL, Redis and `/health/ready`.

Publish `Vatrushka-Setup-0.6.1-x64.exe` and its blockmap before atomically replacing `latest.yml`. Installed 0.6.0 NSIS clients can update in place. The unsigned installer may still show a Windows reputation warning.
