# Vatrushka 0.6.1

Версия 0.6.1 публикует работу над надежностью настроек, обмена сообщениями и совместного использования экрана, выполненную после версии 0.6.0.

## Основные моменты

- исправляет загрузку истории канонического текстового канала и удаление сообщений в реальном времени;
- завершает настройку маршрутизируемого сервера, псевдонимы профиля и синхронизацию присутствия;
- стабилизирует повторное совместное использование экрана, обязательное защищённое системное аудио, выбор качества и полноэкранный просмотр;
- переносит элементы управления громкостью участников и потока в контекстные меню и улучшает поведение наложения;
- обновляет эталонные показатели визуальной регрессии Windows и оставляет updater скрытым, когда новой версии не существует.

## Операции

Раскатка API применяет аддитивную миграцию `0024_server_member_aliases`. Создайте резервную копию PostgreSQL перед заменой образа API, затем проверьте PostgreSQL, Redis и `/health/ready`.

Опубликуйте `Vatrushka-Setup-0.6.1-x64.exe` и его блок-карту до атомарной замены `latest.yml`. Установленные клиенты NSIS версии 0.6.0 могут обновиться на месте. Подписанный установщик по-прежнему может показывать предупреждение о репутации Windows.
