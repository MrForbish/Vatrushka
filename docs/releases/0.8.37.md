# Vatrushka 0.8.37

## Product change

Hawk exception monitoring has been removed from the API and desktop client.
Operational monitoring remains based on Prometheus, Grafana, Loki, and
structured application logs.

## Delivery change

This release removes Hawk catchers, source-map uploads, CI token validation,
runtime configuration, and the related deploy health gate. It does not add
migrations, change API or shared contracts, modify permissions, or alter the
media and realtime architecture.

## Rollback

The release pipeline retains the prior immutable candidate and stable updater
feed. If a regression is found after publication, restore the preceding
verified candidate through the root-owned rollback wrapper; do not overwrite
the immutable tag or release.
