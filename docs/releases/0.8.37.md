# Vatrushka 0.8.37

## Изменение продукта

Мониторинг исключений Hawk был удален из клиентов API и desktop. Операционный мониторинг сохраняется на основе Prometheus, Grafana, Loki и структурированных журналов приложений.

## Изменение доставки

Этот выпуск удаляет перехватчики Hawk, загрузку source-map, проверку токена CI, конфигурацию runtime и связанный контроль развертывания. Он не добавляет миграции, не изменяет API или общие контракты, не модифицирует разрешения и не изменяет архитектуру медиа и реального времени.

## Откат

Релиз pipeline сохраняет предыдущий неизменяемый кандидат и стабильную ленту updater. Если после публикации будет обнаружена регрессия, восстановите предыдущего проверенного кандидата через обертку отката, принадлежащую root; не перезаписывайте неизменяемую метку или релиз.
