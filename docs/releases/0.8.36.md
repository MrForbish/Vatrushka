# Vatrushka 0.8.36

## Product change

Profile settings now present profile data, activity status, and notifications
as one responsive workspace. Global navigation no longer exposes a separate
Community destination; server cards remain the entry point for servers.

## Delivery change

This release updates renderer layout, localized settings copy, and its visual
and Electron regression evidence. It does not add migrations, modify API or
shared contracts, change permissions, or alter deployment topology.

## Rollback

The release pipeline retains the prior immutable candidate and stable updater
feed. If a regression is found after publication, restore the preceding
verified candidate through the root-owned rollback wrapper; do not overwrite
the immutable tag or release.
