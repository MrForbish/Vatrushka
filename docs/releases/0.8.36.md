# Vatrushka 0.8.36

## Изменение продукта

Настройки профиля теперь отображают данные профиля, статус активности и уведомления в виде единого адаптивного рабочего пространства. Глобальная навигация больше не показывает отдельный пункт назначения «Сообщество»; карты серверов остаются точкой входа для серверов.

## Изменение доставки

Этот выпуск обновляет макет renderer, копию локализованных настроек и его визуальные и Electron регрессионные данные. Он не добавляет миграций, не изменяет API или общие контракты, не меняет разрешения и не изменяет топологию развертывания.

## Откат

Релиз pipeline сохраняет предыдущий неизменяемый кандидат и стабильную ленту updater. Если после публикации будет обнаружена регрессия, восстановите предыдущего проверенного кандидата через обертку отката, принадлежащую root; не перезаписывайте неизменяемую метку или релиз.
