# Vatrushka 0.8.8

Makes observability deployment readiness checks robust after configuration-bound services are recreated.

- Prometheus, Loki, Grafana and active Prometheus targets receive a bounded readiness window of up to 60 seconds.
- A real persistent readiness failure still fails deployment with the affected component in the error.
- No PostgreSQL, Redis-key, or S3 lifecycle migration is included.
