# Vatrushka 0.8.8

Делает проверки готовности развертывания наблюдаемости более надежными после воссоздания сервисов, привязанных к конфигурации.

- Prometheus, Loki, Grafana и активные Prometheus цели получают ограниченное окно готовности до 60 секунд.
- Реальная стойкая ошибка готовности по-прежнему приводит к сбою развертывания с затронутым компонентом в ошибке.
- Нет включенной миграции жизненного цикла PostgreSQL, Redis-ключа или S3.
