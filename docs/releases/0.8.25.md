# Vatrushka 0.8.25

Production доставка hotfix.

## Исправлено

- Защищённая вакансия кандидата production явно нацелена на специализированного
Linux исполнитель вместо того, чтобы полагаться на доступность не помеченного исполнителя.
- Создаются кандидатские манифесты и контрольные сумки с правом собственности
и режимы, требуемые обертками развертывания с правами root.
- Набор входных данных публикации updater нормализуется перед передачей, поэтому
Стабильная лента остается защищенной от артефактов, доступных для записи группой или всеми пользователями.
- Ключевой материал Observer SSH нормализуется и проверяется перед развертыванием.
- Детерминированная Windows компактная визуальная базовая оболочка обновляется после
проверенный самостоятельно управляемый исполнитель с дрейфом изображения на 24 пикселя.

## Влияние миграции

- PostgreSQL миграции: отсутствуют.
- Redis ключи: нет.
- S3 жизненный цикл: отсутствует.
- Серьезные изменения: отсутствуют.

## Подтверждение релиза

Защищённый тэг продвигает неизменяемые кандидаты-артефакты, связанные с контрольной суммой, выполняет предварительную проверку production и верификацию Observer, и публикует стабильный updater только после успешного завершения этих этапов.

## Откат

Используйте защищённую задачу `rollback-production-runtime`, чтобы восстановить предыдущего кандидата с проверкой контрольной суммы. Разрушительная понижающая миграция базы данных не выполняется.
