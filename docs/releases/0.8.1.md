# Vatrushka 0.8.1

Version 0.8.1 is a focused reliability release for production diagnostics.

## Fixed

- The **Logs: Overview** Grafana dashboard now keeps a non-empty Loki stream matcher even when all dashboard filters are set to `All`. Loki therefore accepts the query instead of returning a parse error.

## Observability

- Hawk error monitoring is available as an opt-in integration for the API, Electron Main process and renderer.
- Tokens remain server or protected-CI configuration only. API context is scrubbed and user identifiers are pseudonymised before reporting.

## Data and rollback

- No PostgreSQL or Redis migration is included.
- No S3 object or retention policy changes are included.
- To roll back, restore the previous production tag and updater feed. Hawk may be disabled independently with its feature flags.
