# Vatrushka 0.8.1

Версия 0.8.1 является сосредоточенным выпуском по повышению надежности для диагностики production.

## Исправлено

- Панель управления **Логи: Обзор** Grafana теперь сохраняет ненулевой сопоставитель потоков Loki, даже когда все фильтры панели управления установлены на `All`. Loki поэтому принимает запрос, вместо того чтобы возвращать ошибку разбора.

## Наблюдаемость

- Мониторинг ошибок Hawk доступен как интеграция по выбору для API, Electron Главного процесса и renderer.
- Токены остаются только на сервере или в защищённой конфигурации CI. Контекст API очищается, а идентификаторы пользователей псевдонимизируются перед отправкой отчёта.

## Данные и откат

- Миграция PostgreSQL или Redis не включена.
- Не включены изменения объекта S3 или правил хранения.
- Чтобы откатить изменения, восстановите предыдущий тег production и ленту updater. Hawk может быть отключен независимо с его feature flags.
