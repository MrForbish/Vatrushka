# Vatrushka 0.8.21

Desktop UI Kit delivery release.

## Changed

- Reworks the desktop application shell and core Home, server, direct-message,
  notification and settings workspaces around the Vatrushka UI Kit.
- Updates the authentication window, responsive global navigation, profile and voice
  dock, server banner, messaging layout and visual interaction states.
- Preserves existing API/shared contracts, permissions, authentication lifecycle,
  WebSocket/reconnect, LiveKit/media architecture and Electron preload boundary.

## Migration impact

- PostgreSQL migrations: none.
- Redis keys: none.
- S3 lifecycle: none.
- Runtime configuration: none.
- Breaking changes: none.

## Release evidence

- UI Kit MR !130 passed all required CI quality gates.
- Release MR validates version consistency, policy, lint, type checks, Storybook
  interaction tests, Electron end-to-end tests and visual regression tests.

## Rollback

No database, Redis, S3, API contract, authentication or media rollback is required.
