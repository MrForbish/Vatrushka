# Vatrushka 0.8.21

Desktop UI Выпуск доставки набора.

## Изменено

- Переделывает оболочку приложения desktop и основной Home, сервер, личные сообщения,
рабочие пространства уведомлений и настроек вокруг набора Vatrushka UI.
- Обновляет окно аутентификации, адаптивную глобальную навигацию, профиль и голос
панель, баннер сервера, макет сообщений и визуальные состояния взаимодействия.
- Сохраняет существующие API/общие контракты, разрешения, жизненный цикл аутентификации,
WebSocket/переподключение, LiveKit/медиа-архитектура и Electron граница предварительной загрузки.

## Влияние миграции

- PostgreSQL миграции: отсутствуют.
- Redis ключи: нет.
- S3 жизненный цикл: отсутствует.
- Runtime конфигурация: отсутствует.
- Серьезные изменения: отсутствуют.

## Подтверждение релиза

- UI Комплект MR !130 прошел все требуемые контроли качества CI.
- Релиз MR проверяет согласованность версии, политику, lint, проверки типов, Storybook
тесты взаимодействия, Electron сквозные тесты и visual regression тесты.

## Откат

Отмените слияние релиза из `main` и разверните предыдущий неизменяемый тег. Откат базы данных, контрактов Redis, S3, API, аутентификации или медиа не требуется.
