# Vatrushka 0.8.9

Полировка перед выпуском для сообщений, медиа, профиля/активов сервера и операционной диагностики.

- Исправляет расположение разделителя непрочитанного для открытых разговоров и сообщений, отправленных текущим пользователем.
- Восстанавливает явную опцию качества совместного использования экрана 2560 × 1440 / 60 FPS.
- Нормализует загруженные URL-адреса аватара, иконки и обложки в представлениях Главной страницы, сервера, голосовых и прямых сообщений.
- Удаляет полноэкранный режим окна приложения; полноэкранный режим сохраняется только для просмотра при совместном использовании экрана.
- Включает глобальный захват ошибок Hawk renderer, добавляет доступное по желанию событие дыма API и преждевременно завершает пакет production, если отсутствует защищённый токен Hawk.
- Нет включенной миграции жизненного цикла PostgreSQL, Redis-ключа или S3.
