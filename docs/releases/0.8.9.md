# Vatrushka 0.8.9

Pre-release polish for messaging, media, profile/server assets and operational diagnostics.

- Fixes unread-divider placement for open conversations and messages sent by the current user.
- Restores the explicit 2560 × 1440 / 60 FPS screen-share quality option.
- Normalizes uploaded avatar, icon and cover URLs across Home, server, voice and direct-message views.
- Removes the fullscreen mode of the application window; fullscreen is retained solely for screen-share viewing.
- Enables global Hawk renderer error capture, adds an opt-in API smoke event, and fails a production package early if the protected Hawk token is absent.
- No PostgreSQL, Redis-key, or S3 lifecycle migration is included.
