# Vatrushka 0.8.24

Production delivery repair release.

## Changed

- Normalizes CRLF in the Windows-generated desktop checksum sidecar before Linux
  verifies the immutable desktop archive.
- Retains strict SHA-256 validation and the dedicated production deploy identity
  before production preflight.

## Migration impact

- PostgreSQL migrations: none.
- Redis keys: none.
- S3 lifecycle: none.
- Breaking changes: none.

## Release evidence

The protected tag resolves only checksum-bound immutable API and desktop artifacts,
requires production preflight and publishes the stable updater only after runtime
and Observer verification.

## Rollback

Use the protected `rollback-production-runtime` job to restore the prior
checksum-verified candidate. No destructive database down migration is performed.
