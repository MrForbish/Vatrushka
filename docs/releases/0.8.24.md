# Vatrushka 0.8.24

Production выпуск ремонта доставки.

## Изменено

- Нормализует CRLF в побочном файле контрольной суммы desktop, сгенерированном Windows, перед Linux
проверяет неизменяемый архив desktop.
- Сохраняет строгую проверку SHA-256 и специализированную идентичность развертывания production
перед production предполетной проверкой.

## Влияние миграции

- PostgreSQL миграции: отсутствуют.
- Redis ключи: нет.
- S3 жизненный цикл: отсутствует.
- Серьезные изменения: отсутствуют.

## Подтверждение релиза

Защищённый тег разрешает только неизменяемые артефакты API и desktop, привязанные к контрольной сумме, требует предварительной проверки production и публикует стабильный updater только после верификации runtime и Observer.

## Откат

Используйте защищённую задачу `rollback-production-runtime`, чтобы восстановить предыдущего кандидата с проверкой контрольной суммы. Разрушительная понижающая миграция базы данных не выполняется.
