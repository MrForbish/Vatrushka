# Vatrushka 0.8.30

Аварийный выпуск микрофона.

## Исправлено

- LiveKit теперь получает процессор усиления микрофона только после локального аудио
дорожке назначен `AudioContext`. Это восстанавливает активацию микрофона.
- Сбой усилителя WebAudio изолирован от активации микрофона и
зарегистрировано как медиадиагностика.

## Изменено

- Восстановлен стандартный диапазон микрофона 0–100%. Громкость звука уведомления составляет
отдельная локальная настройка и начинается с 60% для новых профилей.

## Влияние миграции

- PostgreSQL миграции: отсутствуют.
- Redis ключи: нет.
- S3 жизненный цикл: отсутствует.
- Серьезные изменения: отсутствуют.

## Подтверждение релиза

hotfix запускает desktop typecheck, целевые регрессионные тесты медиа, desktop сборку и проверку бюджета пакета перед защищенным основным слиянием. Защищенный тег pipeline продвигает неизменяемый кандидат и публикует updater только после runtime и проверки наблюдаемости.

## Откат

Используйте защищённую задачу `rollback-production-runtime`, чтобы восстановить предыдущего кандидата с проверкой контрольной суммы. Стабильная лента updater публикуется только после успешного прохождения проверок runtime и наблюдаемости.
