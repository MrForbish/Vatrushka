# Vatrushka 0.8.30

Emergency microphone recovery release.

## Fixed

- LiveKit now receives the microphone gain processor only after the local audio
  track has an assigned `AudioContext`. This restores microphone activation.
- A WebAudio gain-processor failure is isolated from microphone activation and
  recorded as a media diagnostic.

## Changed

- Restored the standard 0–100% microphone range. Notification sound volume is
  a separate local setting and starts at 60% for new profiles.

## Migration impact

- PostgreSQL migrations: none.
- Redis keys: none.
- S3 lifecycle: none.
- Breaking changes: none.

## Release evidence

The hotfix runs the desktop typecheck, targeted media regression tests, desktop
build and bundle-budget check before the protected main merge. The protected tag
pipeline promotes the immutable candidate and publishes the updater only after
runtime and observability verification.

## Rollback

Use the protected `rollback-production-runtime` job to restore the previous
checksum-verified candidate. The stable updater feed is published only after the
runtime and observability checks succeed.
