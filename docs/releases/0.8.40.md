# Vatrushka 0.8.40

## Изменения

- Вся отслеживаемая Markdown-документация проекта переведена на русский язык.
- Сохранены команды, пути, ссылки, кодовые блоки и технические идентификаторы.
- Шаблоны Merge Request и тестовые ожидания политики репозитория обновлены под русские формулировки.

## Доставка и миграция

Миграции базы данных, изменения публичного API, конфигурации production и перемещение объектов не требуются. Выпуск изменяет только документацию, номера версий и связанные проверки текста.

Подтверждение выпуска предоставляют pipeline подготовки, сборки и выпуска.

## Откат

Восстановите предыдущий проверенный неизменяемый кандидат `0.8.39` штатной обёрткой отката. Не перемещайте тег и не перезаписывайте опубликованные артефакты. Откат схемы или данных не требуется.
