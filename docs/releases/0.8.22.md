# Vatrushka 0.8.22

Infrastructure migration release candidate.

## Changed

- Promotes a single immutable API image, source archive and Windows installer from
  the release candidate into the protected stable-tag pipeline without rebuilding.
- Applies the candidate through root-owned, checksum-verified deployment wrappers.
- Requires production preflight, encrypted PostgreSQL backup where a runtime exists,
  readiness and Observer verification before stable updater publication.

## Migration impact

- PostgreSQL migrations: none.
- Redis keys: none.
- S3 lifecycle: none.
- Runtime configuration: production environment is validated before activation.
- Breaking changes: none.

## Release evidence

- Release-candidate pipeline builds and stores immutable OCI and desktop artifacts.
- Protected tag resolves only those artifacts, then requires the single production
  deployment approval before runtime and observability verification.

## Rollback

Use the protected `rollback-production-runtime` job for the checksum-verified
previous candidate. It does not execute destructive database down migrations.
