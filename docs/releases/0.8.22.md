# Vatrushka 0.8.22

Релиз-кандидат миграции инфраструктуры.

## Изменено

- Продвигает один неизменяемый API образ, исходный архив и Windows установщик из
релиз-кандидат в защищенный стабильный тег pipeline без пересборки.
- Применяет кандидат через обертки развертывания, принадлежащие корню и проверенные по контрольной сумме.
- Требуется production предполетная проверка, зашифрованнаяPostgreSQL резервная копия там, где существует runtime,
готовность и проверка Наблюдателем перед стабильной публикацией updater.

## Влияние миграции

- PostgreSQL миграции: отсутствуют.
- Redis ключи: нет.
- S3 жизненный цикл: отсутствует.
- Конфигурация Runtime: среда production проверяется перед активацией.
- Серьезные изменения: отсутствуют.

## Подтверждение релиза

- Сборки кандидата на выпуск pipeline создают и сохраняют неизменяемые артефакты OCI и desktop.
- Защищённый тег разрешает только эти артефакты, затем требует один production
одобрение развертывания перед runtime и проверкой наблюдаемости.

## Откат

Используйте защищённую задачу `rollback-production-runtime` для предыдущего кандидата, проверенного контрольной суммой. Она не выполняет разрушительные миграции базы данных вниз.
