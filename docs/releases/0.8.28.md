# Vatrushka 0.8.28

Production delivery hotfix.

## Fixed

- Stable updater publication now normalizes transferred inbox files to `0644`
  on the production host before the root-owned wrapper validates and promotes
  the checksum-bound feed.

## Migration impact

- PostgreSQL migrations: none.
- Redis keys: none.
- S3 lifecycle: none.
- Breaking changes: none.

## Release evidence

The reviewed hotfix validates the production updater hand-off. The protected
tag pipeline deploys the immutable candidate, verifies observability, and only
then publishes the stable feed.

## Rollback

Use the protected `rollback-production-runtime` job to restore the previous
checksum-verified candidate. No destructive database down migration is
performed.
