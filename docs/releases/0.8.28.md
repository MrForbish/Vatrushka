# Vatrushka 0.8.28

Production доставка hotfix.

## Исправлено

- Стабильная публикация updater теперь нормализует переданные файлы почтового ящика в `0644`
на хосте production до того, как оболочка, принадлежащая root, проверит и продвинет связанный с контрольной суммой поток.

## Влияние миграции

- PostgreSQL миграции: отсутствуют.
- Redis ключи: нет.
- S3 жизненный цикл: отсутствует.
- Серьезные изменения: отсутствуют.

## Подтверждение релиза

Проверенный hotfix подтверждает передачу production updater. Защищённый тег pipeline разворачивает неизменяемого кандидата, проверяет наблюдаемость и только затем публикует стабильный поток.

## Откат

Используйте защищённую задачу `rollback-production-runtime`, чтобы восстановить предыдущего кандидата с проверкой контрольной суммы. Разрушительная понижающая миграция базы данных не выполняется.
