# Vatrushka 0.8.26

Production доставка hotfix.

## Исправлено

- Пересмотренный `hotfix/X.Y.Z-*` MR теперь производит тот же контрольный суммо-ограниченный результат,
неизменяемые API и Windows desktop артефакты кандидата как `release/X.Y.Z` ветка, прежде чем она сможет слиться с `main`.
- Защищённый стабильный тег pipeline разрешает и продвигает те самые артефакты
от родителя слияния hotfix. Он больше не пытается выполнить поиск пакета, который не может существовать, предотвращая появление кандидата production 404, наблюдавшегося в версии 0.8.25.

## Влияние миграции

- PostgreSQL миграции: нет.
- Redis ключи: нет.
- S3 жизненный цикл: отсутствует.
- Серьезные изменения: отсутствуют.

## Подтверждение релиза

MR проверяет путь создания кандидата hotfix. Затем защищённый тег разрешает неизменяемый манифест и пакет desktop, выполняет предварительные проверки и резервное копирование, и публикует стабильный updater только после успешного прохождения проверки production.

## Откат

Используйте защищённую задачу `rollback-production-runtime`, чтобы восстановить предыдущего кандидата с проверкой контрольной суммы. Разрушительная понижающая миграция базы данных не выполняется.
