# Vatrushka 0.8.26

Production delivery hotfix.

## Fixed

- A reviewed `hotfix/X.Y.Z-*` MR now produces the same checksum-bound,
  immutable API and Windows desktop candidate artifacts as a `release/X.Y.Z`
  branch before it can merge to `main`.
- The protected stable-tag pipeline resolves and promotes those exact artifacts
  from the hotfix merge parent. It no longer attempts a package lookup that
  cannot exist, preventing the production candidate 404 observed in 0.8.25.

## Migration impact

- PostgreSQL migrations: none.
- Redis keys: none.
- S3 lifecycle: none.
- Breaking changes: none.

## Release evidence

The MR validates the hotfix candidate creation path. The protected tag then
resolves the immutable manifest and desktop package, runs preflight and backup,
and publishes the stable updater only after production verification succeeds.

## Rollback

Use the protected `rollback-production-runtime` job to restore the previous
checksum-verified candidate. No destructive database down migration is
performed.
