# Vatrushka 0.8.13

Аварийный ремонт доставки телеметрии.

- Устанавливает время ожидания сканирования продукта API Alloy на четыре секунды, что ниже его пятисекундного интервала.
- Восстанавливает пересылку метрик продукта, включая состояние репортера Hawk.
- Не включена миграция PostgreSQL, миграция по ключу Redis, изменение жизненного цикла S3, сборка desktop или изменение контракта updater.
