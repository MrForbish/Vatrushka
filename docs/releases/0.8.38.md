# Vatrushka 0.8.38

## Product change

Notification loudness is now configured in **My profile → Notifications**.
Audio and video settings use the released camera block in its place, and the
audio section is named **Настройки звука**.

## Delivery change

This release contains no database migration, API or shared-contract change,
permission change, or media architecture change. The desktop client performs
a one-time local-settings migration for legacy installations: microphone,
output, screen-share, and notification volume are set to 50%. Later choices
remain user-controlled and persisted.

## Rollback

If a regression is identified after publication, restore the preceding
verified updater candidate through the root-owned rollback wrapper. Do not
overwrite the immutable release tag or stable updater feed.
