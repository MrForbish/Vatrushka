# Vatrushka 0.8.38

## Изменение продукта

Notification loudness is now configured in **My profile → Notifications**.
Audio and video settings use the released camera block in its place, and the
audio section is named **Настройки звука**.

## Изменение доставки

Этот выпуск не содержит изменений в базе данных, API или изменений общей контракта, изменений разрешений или изменений архитектуры медиа. Клиент desktop выполняет одноразовую миграцию локальных настроек для устаревших установок: микрофон, выход, демонстрация экрана и громкость уведомлений устанавливаются на 50%. Последующие выборы остаются под контролем пользователя и сохраняются.

## Откат

Если после публикации выявляется регрессия, восстановите предыдущего проверенного кандидата updater через оболочку отката, принадлежащую root. Не перезаписывайте неизменяемый тег релиза или стабильный канал updater.
