# Vatrushka 0.6.5

Version 0.6.5 is a delivery-only hotfix for the GitLab production publication step. Application behavior, database schema and observability configuration are unchanged from 0.6.4.

## Fixed

- replaced Bash-only `mapfile` and process substitution with POSIX-compatible `find -exec` release uploads in the Alpine `glab` image;
- added a CI policy test that rejects Bash-only release publication syntax;
- restored the exact trailing newline of the protected OpenSSH deployment key file variable.

## Operations

- 0.6.4 installer/feed publication completed before its GitLab Release upload failed;
- 0.6.5 republishes the same application and observability scope with corrected immutable GitLab Release assets;
- no PostgreSQL migration, Redis key change, S3 lifecycle change or feature flag is introduced;
- rollback returns the updater feed and API/Caddy deployment to 0.6.3, while the separate observability Compose can be stopped without removing volumes.
