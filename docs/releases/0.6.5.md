# Vatrushka 0.6.5

Версия 0.6.5 является только доставкой hotfix для шага публикации GitLab production. Поведение приложения, схема базы данных и конфигурация наблюдаемости остаются без изменений по сравнению с 0.6.4.

## Исправлено

- заменены только для Bash `mapfile` и подстановка процессов на совместимые с POSIX `find -exec` загрузки релизов в образе Alpine `glab`;
- добавлен тест политики CI, который отвергает синтаксис публикации релиза только для Bash;
- восстановил точный завершающий символ новой строки переменной файла ключа развертывания OpenSSH с защитой.

## Операции

- Публикация установщика/канала версии 0.6.4 завершена до того, как его GitLab Загрузка релиза не удалась;
- 0.6.5 повторно публикует тот же объем приложения и наблюдаемости с исправленными неизменяемыми GitLab релизными активами;
- нет PostgreSQL миграции, Redis изменения ключа, S3 изменения жизненного цикла или feature flag введено;
- откат возвращает канал updater и развертывание API/Caddy к версии 0.6.3, в то время как отдельный компонент наблюдения Compose можно остановить без удаления томов.
