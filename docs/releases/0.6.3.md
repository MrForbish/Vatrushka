# Vatrushka 0.6.3

Version 0.6.3 completes the current operational-readiness slice and ships the desktop, server-shell and CI improvements accumulated in `develop` after 0.6.2.

## Added

- synchronized microphone mute and incoming-audio deafen controls in the profile rail;
- server descriptions, permission-gated channel rename and realtime server/channel updates;
- compact `CEO Founder` platform-owner presentation without highlighted message backgrounds;
- secure email-code password reset with neutral account lookup, atomic session revocation, presence cleanup and security notification;
- guarded capacity-check tooling for API, WebSocket, PostgreSQL, Redis, S3 and the LiveKit control plane.

## Changed

- ordinary, release-candidate, production and sync workflows now use the documented branch policy and immutable release evidence;
- desktop behavior and static Storybook visual suites run as parallel CI jobs with explicit duration budgets and supported boundary viewports;
- completed settings fallbacks and the unreachable legacy server-settings modal were removed; channel permission overrides use routed production settings.

## Operations

- no database migration is introduced by this release; the candidate still verifies upgrade compatibility against the 0.6.2 production schema;
- build the Windows client with `VITE_PUBLIC_API_BASE_URL=https://api.myvatrushka.ru`;
- code signing remains unavailable, so the accepted Windows SmartScreen warning risk is unchanged;
- after deployment, run the guarded production smoke profile first and record capacity evidence before any larger baseline;
- rollback restores the previous API application commit and the previous atomic `latest.yml`; additive database schema is left in place.
