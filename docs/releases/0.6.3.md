# Vatrushka 0.6.3

Версия 0.6.3 завершает текущий этап готовности к эксплуатации и поставляет улучшения desktop, серверной оболочки и CI, накопленные в `develop` после версии 0.6.2.

## Добавлено

- синхронизированные управление отключением микрофона и заглушением входящего аудио в панели профиля;
- описания сервера, переименование канала с ограничением по правам и обновления сервера/канала в реальном времени;
- компактная презентация владельца платформы `CEO Founder` без выделенных фонов сообщений;
- безопасный сброс пароля по коду электронной почты с нейтральной проверкой учетной записи, атомарным аннулированием сессии, очисткой присутствия и уведомлением о безопасности;
- защищенные инструменты проверки емкости для API, WebSocket, PostgreSQL, Redis, S3 и управляющей плоскости LiveKit.

## Изменено

- обычные, предварительные версии-релизы, production и синхронизационные рабочие процессы теперь используют задокументированную политику веток и неизменяемые доказательства выпуска;
- Поведение desktop и статические Storybook визуальные наборы выполняются как параллельные CI задания с явными бюджетами продолжительности и поддерживаемыми граничными окнами просмотра;
- Завершенные настройки резервного копирования и недоступная модальная форма настроек устаревшего сервера были удалены; переопределения разрешений каналов используют маршрутизированные production настройки.

## Операции

- эта версия не вводит миграцию базы данных; кандидат по-прежнему проверяет совместимость обновления с схемой 0.6.2 production;
- построить клиента Windows с `VITE_PUBLIC_API_BASE_URL=https://api.myvatrushka.ru`;
- подпись кода остается недоступной, поэтому принятый риск предупреждения SmartScreen Windows остается неизменным;
- после развертывания сначала выполните защищённый дымовой профиль production и зафиксируйте доказательства ёмкости перед любым большим базовым значением;
- откат восстанавливает предыдущий коммит приложения API и предыдущий атомарный `latest.yml`; добавочная схема базы данных оставляется на месте.
