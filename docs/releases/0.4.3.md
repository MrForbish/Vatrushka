# Vatrushka 0.4.3

Version 0.4.3 replaces user-entered server invite codes with short HTTPS invite links. Existing stored invite identifiers are reused as opaque link tokens, so no database migration is needed.

## User-visible changes

- “Пригласить на сервер” opens a real dialog containing a short `https://myvatrushka.ru/i/...` link.
- Copying has visible progress, success and failure states.
- Opening the link launches Vatrushka, waits for authentication/profile completion if needed, accepts the invitation and opens the server.
- Reopening a link for an existing membership is idempotent and simply opens the server.
- All manual invite-code fields and “Войти по коду” actions are removed.

## API and infrastructure

- Server summaries/details expose `inviteUrl`; `inviteCode` is no longer public.
- `POST /api/v1/invites/:inviteToken/accept` replaces `POST /api/v1/servers/join`.
- `GET /i/:inviteToken` redirects to the validated `vatrushka://invite/:inviteToken` deep link.
- `PUBLIC_INVITE_URL` controls generated links and `INVITE_DOMAIN` configures the dedicated Caddy TLS host.

## Rollout

Point `myvatrushka.ru` and `api.myvatrushka.ru` to the VPS. Set `PUBLIC_INVITE_URL=https://myvatrushka.ru` and `INVITE_DOMAIN=myvatrushka.ru`, then rebuild API and recreate Caddy before publishing the 0.4.3 desktop feed. Older invite codes are not accepted manually; links generated by 0.4.3 remain valid for existing servers.
