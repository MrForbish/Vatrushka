# Vatrushka 0.4.3

Версия 0.4.3 заменяет введённые пользователями коды приглашений на сервер с короткими ссылками-приглашениями HTTPS. Существующие сохранённые идентификаторы приглашений используются повторно как непрозрачные токены ссылок, поэтому миграция базы данных не требуется.

## Изменения, видимые пользователю

- “Пригласить на сервер” opens a real dialog containing a short `https://myvatrushka.ru/i/...` link.
- Копирование имеет видимые состояния прогресса, успешного выполнения и неудачи.
- Открытие ссылки запускает Vatrushka, при необходимости ждёт аутентификации/завершения профиля, принимает приглашение и открывает сервер.
- Повторное открытие ссылки для существующего членства идемпотентно и просто открывает сервер.
- All manual invite-code fields and “Войти по коду” actions are removed.

## API и инфраструктура

- Сводки/подробности сервера раскрывают `inviteUrl`; `inviteCode` больше не является общедоступным.
- `POST /api/v1/invites/:inviteToken/accept` заменяет `POST /api/v1/servers/join`.
- `GET /i/:inviteToken` перенаправляет на проверенный `vatrushka://invite/:inviteToken` deep link.
- `PUBLIC_INVITE_URL` управляет сгенерированными ссылками, а `INVITE_DOMAIN` настраивает выделенный хост Caddy TLS.

## Внедрение

Укажите `myvatrushka.ru` и `api.myvatrushka.ru` на VPS. Установите `PUBLIC_INVITE_URL=https://myvatrushka.ru` и `INVITE_DOMAIN=myvatrushka.ru`, затем перестройте API и воссоздайте Caddy перед публикацией ленты 0.4.3 desktop. Старые коды приглашений не принимаются вручную; ссылки, сгенерированные в 0.4.3, остаются действительными для существующих серверов.
