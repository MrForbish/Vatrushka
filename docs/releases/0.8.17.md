# Vatrushka 0.8.17

Reliable Windows Hawk release packaging.

- GitLab CI now preserves the protected Desktop Main and Desktop Renderer Hawk integration tokens.
- The Windows package job validates the token structure without printing a secret and passes renderer-only aliases to the Electron build at runtime.
- This resolves the `v0.8.16` packaging failure where a YAML self-reference was delivered as a literal token value.
- No PostgreSQL migration, Redis-key migration, S3 lifecycle change, or client-facing API contract change.

## Rollback

Restore the prior application commit/image and prior stable `latest.yml`.
No database rollback is required. Reverting this release restores the previous
CI configuration but does not affect authentication, voice, messaging, or media.
