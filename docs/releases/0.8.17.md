# Vatrushka 0.8.17

Надежная упаковка для выпуска Hawk Windows.

- GitLab CI теперь сохраняет защищенные интеграционные токены Desktop Main и Desktop Renderer Hawk.
- Пакетная задача Windows проверяет структуру токена без вывода секрета и передает псевдонимы только для renderer сборке Electron на runtime.
- Это решает проблему с упаковкой `v0.8.16`, при которой YAML само-ссылка передавалась как буквальное значение токена.
- Нет миграции PostgreSQL, миграции по ключу Redis, изменения жизненного цикла S3 или изменения контракта API, ориентированного на клиента.

## Откат

Восстановите предыдущий коммит/образ приложения и предыдущую стабильную версию `latest.yml`. Откат базы данных не требуется. Откат этого выпуска восстанавливает предыдущую конфигурацию CI, но не влияет на аутентификацию, голос, сообщения или мультимедиа.
