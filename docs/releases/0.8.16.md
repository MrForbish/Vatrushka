# Vatrushka 0.8.16

Reliable Hawk release publication for API and the Windows desktop client.

- Desktop Main and Renderer publish their source maps under the immutable release tag.
- A rejected desktop source-map upload stops Windows packaging and reports the safe Hawk HTTP failure detail.
- API publishes compiled source maps after startup; a Hawk outage is logged but never reduces API availability.
- No PostgreSQL migration, Redis-key migration, S3 lifecycle change, or client-facing API contract change.

## Rollback

Restore the previous application commit/image and previous stable `latest.yml`.
No database rollback is required. Reverting this release removes automated Hawk
release publication but does not affect authentication, voice, messaging, or
media functionality.
