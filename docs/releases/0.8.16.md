# Vatrushka 0.8.16

Публикация надежного выпуска Hawk для клиента API и Windows desktop.

- Desktop и Renderer публикуют свои исходные карты под неизменяемым тегом выпуска.
- Отклонённая загрузка карты исходников desktop останавливает упаковку Windows и сообщает безопасную деталь ошибки Hawk HTTP.
- API публикует скомпилированные карты исходного кода после запуска; сбой Hawk регистрируется, но никогда не снижает доступность API.
- Нет миграции PostgreSQL, миграции по ключу Redis, изменения жизненного цикла S3 или изменения контракта API, направленного на клиента.

## Откат

Восстановите предыдущий коммит/образ приложения и предыдущую стабильную версию `latest.yml`. Откат базы данных не требуется. Возврат этой версии удаляет автоматическую публикацию релиза Hawk, но не влияет на функциональность аутентификации, голосовых вызовов, сообщений или медиа.
