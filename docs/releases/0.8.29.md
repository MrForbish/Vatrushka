# Vatrushka 0.8.29

Feature and reliability release.

## Changed

- Added independently persisted microphone and output-volume controls in user
  settings and voice-channel device menus.
- Registration now collects a unique username. Username changes remain limited
  to once per seven days.
- The notification center now shows the installed application version.

## Fixed

- Structured log ingestion now normalizes fallback records and makes JSON
  parsing diagnostics actionable in Grafana.
- Profile avatars and covers update immediately after edits, retry a transient
  image-load failure once, and preserve the last displayed image during reload.

## Migration impact

- PostgreSQL migrations: none.
- Redis keys: none.
- S3 lifecycle: none.
- Breaking changes: none.

## Release evidence

The assembly pipeline validates the complete quality gate, PostgreSQL and Redis
integration tests, Windows RC packaging, release metadata and performance
budgets. The protected tag pipeline promotes the checksum-bound release
candidate, verifies runtime readiness and observability, then publishes the
stable updater feed last.

## Rollback

Use the protected `rollback-production-runtime` job to restore the previous
checksum-verified candidate. The stable updater feed is updated only after the
runtime and observability checks succeed; no destructive database down
migration is performed.
