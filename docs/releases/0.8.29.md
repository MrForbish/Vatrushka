# Vatrushka 0.8.29

Выпуск функций и надежности.

## Изменено

- Добавлены независимо сохраняемые элементы управления микрофоном и уровнем громкости в пользовательском интерфейсе
настройки и меню устройств голосового канала.
- Регистрация теперь собирает уникальное имя пользователя. Изменения имени пользователя остаются ограниченными
один раз в семь дней.
- Центр уведомлений теперь показывает версию установленного приложения.

## Исправлено

- Структурированное поглощение логов теперь нормализует резервные записи и делает JSON
диагностика синтаксического анализа доступна для действий в Grafana.
- Аватары и обложки профиля обновляются сразу после редактирования, попробуйте снова при временной ошибке
сбой загрузки изображения один раз и сохранение последнего отображаемого изображения при перезагрузке.

## Влияние миграции

- PostgreSQL миграции: отсутствуют.
- Redis ключи: нет.
- S3 жизненный цикл: отсутствует.
- Серьезные изменения: отсутствуют.

## Подтверждение релиза

Сборка pipeline проверяет полный контроль качества, интеграционные тесты PostgreSQL и Redis, упаковку RC Windows, метаданные релиза и показатели производительности. Защищённый тег pipeline продвигает контрольную версию с контрольной суммой, проверяет готовность и наблюдаемость runtime, а затем публикует стабильный feed updater последним.

## Откат

Используйте защищённую задачу `rollback-production-runtime` для восстановления предыдущего кандидата с проверкой контрольной суммы. Стабильный поток updater обновляется только после успешного выполнения проверок runtime и наблюдаемости; разрушительная понижающая миграция базы данных не выполняется.
