# Vatrushka 0.8.34

## Product change

Voice channels support camera publishing and viewing for members granted
`STREAM_VIDEO`.

## Delivery change

`0027_stream_video_default_role.sql` is explicitly classified as
backward-compatible for delivery. It only appends `STREAM_VIDEO` to existing
ordinary-role permissions; channel and member deny overwrites stay effective.
All migrations not listed in `scripts/delivery/migration-compatibility.json`
continue to require manual review.

## Rollback

The release pipeline keeps the preceding immutable candidate available. The
deployment wrapper rejects invalid or manual-review manifests before changing
the active runtime symlink.
