# Vatrushka 0.8.34

## Изменение продукта

Голосовые каналы поддерживают публикацию и просмотр камеры для участников, которым предоставлен `STREAM_VIDEO`.

## Изменение доставки

`0027_stream_video_default_role.sql` явно классифицирован как обратно совместимый для доставки. Он только добавляет `STREAM_VIDEO` к существующим разрешениям обычной роли; переопределения запрета для каналов и участников остаются эффективными. Все миграции, не указанные в `scripts/delivery/migration-compatibility.json`, по-прежнему требуют ручной проверки.

## Откат

Релиз pipeline сохраняет предыдущий неизменяемый кандидат доступным. Оболочка развертывания отклоняет недопустимые или требующие ручного обзора манифесты перед изменением активной символической ссылки runtime.
