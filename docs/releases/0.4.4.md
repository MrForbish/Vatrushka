# Vatrushka 0.4.4

Версия 0.4.4 — это релиз надежности медиа desktop, основанный на реальном тесте с двумя участниками. Она поддерживает стабильность регулировки громкости участников, улучшает детализацию совместного экрана, предотвращает утечку голосового вывода Vatrushka в общий системный звук и защищает публикацию во время повторных подключений LiveKit.

## Изменения, видимые пользователю

- Ползунок громкости участника больше не исчезает и не перемещается, когда этот участник начинает говорить.
- Ползунки громкости участника и общего доступа к экрану постоянно видимы и выровнены внутри их карточек.
- Общий доступ к экрану сохраняет исходные пропорции до 2560×1440 при 30 FPS с потолком 8 Мбит/с.
- Совместное использование системного аудио является fail-closed: если Chromium не может подтвердить, что собственный вывод Vatrushka исключен, небезопасное совместное использование останавливается, и видео можно поделиться без аудио.
- Всплывающие окна настроек и модальные диалоги закрываются, когда пользователь щелкает вне их.
- Совместное использование экрана не может начаться, пока LiveKit переподключается; пользователи видят инструкцию по восстановлению вместо `publishing rejected as engine not connected within timeout`.

## Проверка

- TypeScript typecheck и ESLint.
- Общие, API и renderer модульные тесты.
- Storybook тесты взаимодействия и доступности.
- Windows visual regression, включая постоянные элементы управления участниками и громкость звука при демонстрации экрана.
- Electron E2E и production проверка бюджета пакета.

Захват обратной петли и его акустический результат не могут быть точно воспроизведены CI. Перед широким развёртыванием повторите матрицу двух машин Windows с `docs/testing.md`: говорите через удалённого участника, пока аудио системы передаётся, и убедитесь на принимающем клиенте, что участник слышен только через дорожку микрофона, никогда через `ScreenShareAudio`.

## Развертывание

В версии 0.4.4 нет миграции базы данных или конфигурации сервера. Обновите серверную версию для отслеживания, затем опубликуйте `Vatrushka-Setup-0.4.4-x64.exe`, его блок-карту и переносимый артефакт. Заменяйте `latest.yml` только после того, как будут доступны соответствующие установка и блок-карта; установленные клиенты 0.4.x обновятся на месте.
