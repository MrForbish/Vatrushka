# Vatrushka 0.4.4

Version 0.4.4 is a desktop media reliability release based on a real two-participant test. It keeps participant volume controls stable, improves screen-share detail, prevents Vatrushka voice output from leaking into shared system audio, and guards publication during LiveKit reconnects.

## User-facing changes

- A participant's volume slider no longer disappears or moves when that participant starts speaking.
- Participant and screen-share audio sliders are permanently visible and aligned inside their cards.
- Screen sharing preserves source proportions up to 2560×1440 at 30 FPS with an 8 Mbps ceiling.
- System-audio sharing is fail-closed: if Chromium cannot confirm that Vatrushka's own output is excluded, the unsafe share is stopped and video can be shared without audio.
- Settings popovers and modal dialogs close when the user clicks outside them.
- Screen sharing cannot start while LiveKit is reconnecting; users see a recovery instruction instead of `publishing rejected as engine not connected within timeout`.

## Validation

- TypeScript typecheck and ESLint.
- Shared, API and renderer unit tests.
- Storybook interaction and accessibility tests.
- Windows visual regression, including persistent participant controls and screen-share audio volume.
- Electron E2E and production bundle budget checks.

Loopback capture and its acoustic result cannot be reproduced faithfully by CI. Before broad rollout, repeat the two-machine Windows matrix from `docs/testing.md`: speak through the remote participant while system audio is being shared and confirm on the receiving client that the participant is audible only through the microphone track, never through `ScreenShareAudio`.

## Deployment

There is no database or server configuration migration in 0.4.4. Update the server checkout for traceability, then publish `Vatrushka-Setup-0.4.4-x64.exe`, its blockmap and the portable artifact. Replace `latest.yml` only after the referenced setup and blockmap are available; installed 0.4.x clients will update in place.
