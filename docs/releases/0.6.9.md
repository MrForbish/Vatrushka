# Vatrushka 0.6.9

Версия 0.6.9 исправляет задержку обнаружения обновления клиента Windows.

## Исправлено

- проверяет канал стабильных обновлений сразу после того, как окно desktop готово;
- проверяет ленту каждые 15 минут вместо каждых четырех часов;
- повторные проверки после того, как приложение вновь получает фокус, и после возобновления Windows из режима сна;
- ограничивает проверки, вызываемые активностью, до одного запроса каждые пять минут.

## Операции

- не вводится PostgreSQL миграция, Redis изменение ключа, S3 изменение жизненного цикла или feature flag;
- откат восстанавливает предыдущую сборку desktop и метаданные updater; состояние сервера не изменяется.
