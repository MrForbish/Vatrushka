# Vatrushka 0.6.9

Version 0.6.9 fixes delayed Windows client update discovery.

## Fixed

- checks the stable update feed immediately after the desktop window is ready;
- checks the feed every 15 minutes instead of every four hours;
- rechecks after the application regains focus and after Windows resumes from sleep;
- rate-limits activity-triggered checks to one request per five minutes.

## Operations

- no PostgreSQL migration, Redis key change, S3 lifecycle change or feature flag is introduced;
- rollback restores the previous desktop build and updater metadata; server state is unchanged.
