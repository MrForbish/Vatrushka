# Скриншоты для README

Сняты 2026-09-28 из существующих Storybook-сценариев текущего renderer: `home-homepage--returning-user` и `screens-server--connected-voice`. Данные демонстрационные; production-аккаунты и приватные переписки не используются.

Параметры: Chromium из зафиксированного Playwright, 1600×1000, тёмная тема, `ru-RU`, `Europe/Moscow`, масштаб 1. Снимок делается после загрузки шрифтов и изображений, анимации отключены. Браузерная рамка и панели Storybook не входят в изображение.

Для обновления соберите `npm run build:storybook`, запустите `npm run visual:serve -w @vatrushka/desktop` и откройте `/iframe.html?id=<story-id>&viewMode=story` на локальном сервере. Сохраняйте реальные снимки renderer без дорисовки элементов интерфейса.
